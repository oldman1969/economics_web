## 四、核心设计：14 条预警规则体系

> 经历过"29 条 → 16 条 → 14 条"的精简演进。核心理念：**一只票一个方向只出一条预警，去冗余、去噪声**。

### 4.1 卖出 / 风险信号（破位·见顶·离场）

| ID | 规则名 | 级别 | 权重 | 说明 |
|----|--------|------|------|------|
| R01 | **见顶阶梯** | 🔴 CRITICAL | A级 | 合并阶梯：对子顶/巨量见顶/第二波见顶/长上影/跳空衰竭/纺锤线/长下影见顶（弱提醒）/涨停封板/涨停炸板/巨量异动。**按严重度择优只出一条** |
| R02 | **离场阶梯** | 🔴 CRITICAL | A级 | 合并阶梯：急跌/5·13死叉(破55日线才清仓)/5·10死叉/破趋势线+破MA60/有效跌破10日线/跌破5日线/破趋势线/跌破10日线待确认。**按严重度择优只出一条** |
| R03 | 跌破55日线 | 🟡 WARNING | B级 | 收盘跌破MA55进入非多头区域，55日线定大势 |
| R14 | 筹码高位套牢 | 🟡 WARNING | B级（参考） | 获利盘<40% 且主峰高于现价5% 且20日涨幅>15%（参考级，不作一票否决） |

### 4.2 买入 / 机会信号（金叉·突破·站稳）

| ID | 规则名 | 级别 | 权重 | 说明 |
|----|--------|------|------|------|
| R04 | 5/13金叉 | 🔵 INFO | A级 | MA5上穿MA13；放量+站上55日线→强买(A级)，否则谨慎(B级) |
| R05 | 5/10金叉 | 🔵 INFO | B级 | MA5上穿MA10；放量确认短线启动，与R04同时出现属多重确认 |
| R06 | 止跌企稳 | 🔵 INFO | A级 | 抛压释放>10% + 新低区锤子线（下影≥实体×2 + 上影<1%）或十字星 |
| R07 | RSI超卖 | 🔵 INFO | A级 | RSI(6)<20，且**非强下行趋势**（MA20下行+破MA20时过滤，避免接飞刀） |
| R08 | 反包入场 | 🔵 INFO | B级 | 回调后放量反包突破，W型/C浪企稳突破 |
| R09 | 黄金位反弹 | 🔵 INFO | B级 | 回调至黄金分割位 38.2%-61.8% 放量反弹 |
| R10 | 箱体信号 | 🔵 INFO | B级 | 箱体突破(40日振幅<20% + 突破>3% + 放量) 或箱体吸筹(60日箱体+放量小阳) |
| R11 | 均线多头排列 | 🔵 INFO | B级 | MA5>MA13>MA55 且股价站上MA55，且多头排列**刚刚形成** |
| R12 | 站稳五日线加仓 | 🔵 INFO | B级 | 连续3日收盘站上MA5且MA5上行，站稳**刚刚形成**才报 |

### 4.3 参考信号（辅助判断，不参与买卖决策）

| ID | 规则名 | 说明 |
|----|--------|------|
| R13 | 筹码低位密集 | 90%集中度<0.18 且获利盘>60% 且主峰接近/低于现价（参考级，不作一票通过） |
| R14 | 筹码高位套牢 | （同时归入卖出侧 WARNING） |

### 4.4 关键设计模式

**① 阶梯合并（R01/R02）**
```
同一方向多个子信号 → 按严重度排序 → 只展示最严重的一条
避免："一只股票同时弹 5 条卖出预警"的刷屏问题
```

**② 买入共振强度档位**
```
同日多个买入信号 → 折叠为「买入共振·N条」卡片
按 A级=2分 / B级=1分 加权求和 → 4 档：
  弱观察 → 温和看多 → 较强看多 → 强烈共振
含放量确认可额外 +1 档
```

**③ 分级买卖点**
```
5/13金叉不是二元信号：
  放量 + 站上55日线 → A级强买
  放量 + 未站上55日线 → B级谨慎
  缩量 → 可能是假信号，需MACD确认
```

**④ 阶梯式减仓（10日线为卖出主线）**
```
破5日线 → 先减
有效破10日线 → 大减
真死叉(破55日线)/急跌/破MA60 → 清仓
```

**⑤ 参考级标注**
```
R13/R14 明确标注「参考级，不作为一票通过/否决」
防止用户过度依赖单一辅助指标
```

**⑥ 趋势过滤防接飞刀**
```
RSI超卖信号：若 MA20 下行且价格破 MA20 → 直接过滤不报
下跌趋势中的"超卖"只会更超卖
```

**⑦ 状态去重（刚刚形成）**
```
均线多头排列、站稳五日线 → 只在形态"刚刚形成"的首日触发
避免同一状态连续多日重复预警
```

## 六、AI 分析系统

### 6.1 三个子模块（Tab 切换）

| 模块 | 功能 |
|------|------|
| **深度分析** | 目标价/止损/仓位建议由规则引擎定区间；历史建议胜率统计（T+5/10/20）；龙虎榜机构/游资席位解读 |
| **AI筛选** | 规则硬筛 → 多因子打分 → AI横向重排 → 风险/组合约束；4 个策略预设（动量突破/高质量/均衡筛选/低波防守）；每日自动跑、全员共享 |
| **AI对话** | 多轮对话 + 多标的对比（最多 5 只，横向对比行情/基本面/筹码）；可查询筹码分布工具 |

### 6.2 多模型配置（stock-ai-store）

```typescript
{
  profiles: [{
    id: string,
    name: string,
    baseUrl: string,   // OpenAI 兼容接口地址
    model: string,     // 如 glm-4.7-flash（智谱 GLM 系列）
    apiKey?: string
  }],
  currentProfileId: string,
  history: [],          // 分析历史，最多保留 100 条
  chatMessages: [],     // 当前对话
  compareCodes: [],     // 对比标的
}
```

- 不绑定单一厂商，任何 OpenAI 兼容 API 都能接
- 有模型迁移逻辑（旧配置 glm-4-flash 自动升级到 glm-4.7-flash）

### 6.3 数据源增强

AI 分析接入的专业数据（来自 Tushare）：
- 资金流向（大中小单结构）
- 融资融券余额
- 龙虎榜（机构/游资席位）
- 筹码分布（主峰/平均成本/获利盘/集中度）

## 七、复盘系统（数据闭环）

每周五晚自动生成周报，四个标签页：

| 标签 | 内容 |
|------|------|
| 盘前提示 | 每日盘前要点 |
| 日报 | 当日市场回顾 |
| 周报 | 市场宽度/涨跌家数/涨停情绪/北向资金 |
| 胜率复盘 | 深度分析胜率、AI筛选 T+1 胜率、预警规则健康 |

**预警规则健康面板**（值得借鉴的核心机制）：
- 每条规则的 T+5 收益胜率
- 样本数、T+5 均值、近30天胜率
- 样本不足灰显，用数据淘汰噪声规则

实测周报数据样例（2026-08-03 周）：
```
AI 筛选 T+1 胜率 42.2%（263 样本）
  动量突破 53.8% / 高质量 49.2% / 均衡筛选 33.8% / 低波防守 25%
做T信号：买点次日命中 63.6%，卖点次日命中 17.1%
预警触发 3577 次（巨量异动 466、5/10金叉 345、5/13金叉 250…）
```

## 八、云同步机制

- **配对码建信任**：生成配对码 → 另一设备输入配对码完成配对
- **端到端加密**：Web Crypto API 加密后才上传，服务器只见密文
- **gzip 压缩**：CompressionStream 压缩传输
- **版本号冲突控制**：baseVersion 比对，409 冲突时拉取对端更新
- **同步内容**：自选股、分组、AI 配置、分析历史
- 提示语："已拉取另一设备的更新"
