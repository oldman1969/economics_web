## 二、全书 10 章结构

### 核心公式（贯穿全书）

```
Agent = LLM（大脑）+ 上下文（眼睛）+ 工具（手脚）
生产形态 = Model + Harness = LLM + [上下文 + 工具 + 约束 + 验证 + 纠正]
```

## 三、与已有知识库的关系

```
你已有的三块（notes + deep-dives + Prince）回答了：
  "模型怎么算"、"为什么这么设计"、"数学上怎么推导"

这本书回答的是你没覆盖的：
  "模型外面要包什么，才能从 Demo 变成可靠的产品"
```

**核心新增概念（Prince 和你的 deep-dives 都没讲的）**：

1. **Harness 工程** —— 约束、验证、纠正三层保障机制（第 1 章）
2. **上下文工程**（区别于提示工程）—— KV Cache 友好设计、状态栏、分层压缩（第 2 章）
3. **工具设计**（ACI）—— 从 Agent 视角设计接口，而非程序员视角（第 1、4 章）
4. **Agent 评估** —— 没有评估就没有进步，LLM-as-a-Judge（第 6 章）
5. **代码即元能力** —— Agent 用代码思考、用代码自举（第 5 章）

## 四、推荐学习路径

```
第一遍（建立全局）: 第 1 章 Harness 工程 → 理解"模型之外的竞争力"这个总论点
第二遍（三大支柱深挖）: 第 2 章上下文 → 第 3 章记忆 → 第 4 章工具
第三遍（应用与进阶）: 第 5 章 Coding → 第 6 章评估 → 第 8 章自我进化
第四遍（前沿）: 第 9 章多模态 → 第 10 章多 Agent
（第 7 章后训练可与 deep-dives/07、16 对照读）
```
