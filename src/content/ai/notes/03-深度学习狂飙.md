# 第三课：深度学习狂飙（2012–2017）

> 核心问题：从 AlexNet 到 Transformer 之间的五年，发生了什么让"注意力"登上王座？

## 1. 视觉侧的军备竞赛（2012–2015）

AlexNet 之后，ImageNet 竞赛成了架构创新的试验场：

- **VGG（2014）**：证明"用 3×3 小卷积核把网络做深（16-19 层）"就是有效
- **GoogLeNet/Inception（2014）**：同一层并行多种尺寸的卷积，22 层
- **ResNet（2015，何恺明等）**：**残差连接**——让网络学习 `输出 = F(x) + x` 而不是 `F(x)`，梯度可以经由恒等捷径无损回传，**152 层**也能训练。错误率降到 3.57%，首次超越人类水平（约 5%）

> 💡 残差连接这个看似微小的设计，后来出现在**每一个 Transformer 层**里。深度学习史反复证明：让梯度流得顺畅，是最重要的事情。

## 2. 词向量：把"意思"变成数字（2013）

NLP 侧的革命从 **word2vec**（Mikolov，Google，2013）开始：

- 核心思想："**一个词的意义由它的上下文决定**"（分布假设）。用浅层网络预测词的邻居，训练后每个词得到一个几百维的向量
- 向量空间里出现了惊人的代数结构：

```
vec("国王") - vec("男人") + vec("女人") ≈ vec("女王")
vec("巴黎") - vec("法国") + vec("中国") ≈ vec("北京")
```

- 意义第一次变成了**可以计算的几何对象**。今天的 LLM 里，每个 token 的第一站仍然是这样的嵌入向量——只不过维度从 300 涨到了上万。

## 3. Seq2Seq：端到端翻译（2014）

**Sutskever（没错，AlexNet 那位）**在 Google 提出 Seq2Seq：

- 编码器 LSTM 读入整句英文，压缩成**一个固定长度的向量**
- 解码器 LSTM 从这个向量逐词生成法文翻译
- 第一次证明：端到端神经网络可以打败统治机器翻译几十年的短语统计系统

但它有一个明显的瓶颈：**整句话的信息必须塞进一个固定长度的向量**。句子一长，信息就装不下了。

## 4. 注意力机制：天才的一瞥（2014–2015）

**Bahdanau 等**为 Seq2Seq 打上了补丁，这个补丁后来比主体还重要：

> 解码器每生成一个词时，**回头看编码器的所有位置**，用可学习的权重决定"现在该重点看哪几个词"，然后取这些位置的加权和。

- 翻译"欧洲经济区"时，注意力权重会高亮法文原文中对应的三个词——对齐第一次是**学出来**的，而不是规则写出来的
- 信息不再被固定向量瓶颈挤压：任意长度的输入都可以被"按需查阅"

> 💡 **本课最关键的概念**：注意力的本质是**软性的检索**——拿着当前的需求（query），去所有历史信息里算相关度，然后按相关度加权取回信息。记住这个表述，第四课讲 QKV 时你会发现 Transformer 就是把这一句话做成了全部。

## 5. 同期值得一提的三件事

- **GAN（Goodfellow，2014）**：生成器与判别器对抗训练，图像生成质量的第一次飞跃（生成模型另一条路线的起点，后来扩散模型接棒）
- **AlphaGo（DeepMind，2016）**：深度学习（价值/策略网络）+ 强化学习 + 蒙特卡洛树搜索，4:1 战胜李世石。公众第一次真切感到"AI 来了"；Ilya、Hinton 等人的判断被验证
- **神经机器翻译全面替代统计翻译（2015–2016）**：Google 翻译切换到神经网络后，质量一夜之间肉眼可见地提升

## 6. 黎明前的瓶颈：为什么还需要一次革命

到 2016 年，最好的序列模型都是"**RNN/LSTM + 注意力**"，但 RNN 有两个无法根治的病：

1. **无法并行**：第 t 步的计算依赖第 t-1 步的隐藏状态，句子再长也只能一个词一个词地算。GPU 有几千个核心在干等——这与"算力爆炸"的时代趋势背道而驰
2. **长距离依赖仍然衰减**：信息要沿途经过几百步传递，再强的门控也会磨损

> ⏳ 历史在这里等待一个方案：**能不能扔掉循环，只保留注意力？** 2017 年，Google 的 8 个人回答了这个问题。

## 📌 本课要点

1. ResNet 的残差连接解决深度问题，至今存在于每个 Transformer 层
2. word2vec 让意义变成可计算的向量，是 LLM 嵌入层的源头
3. Seq2Seq 有固定向量瓶颈，注意力机制（软性检索）解决了它
4. RNN 无法并行、长程衰减，时代呼唤"纯注意力"架构
