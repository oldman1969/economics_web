# 第六课：对齐与 ChatGPT（2022–2023）

> 核心问题：读完了整个互联网的"野生天才"，怎么变成听话的助手？

## 1. 问题的本质：训练目标错了

GPT-3 的训练目标是"预测互联网文本的下一个词"。互联网文本里，一个问题后面跟着的往往是更多问题（论坛帖），而不是答案。所以模型不听话不是 bug，是**它忠实地完成了自己的训练目标**。

需要的改变：从"续写文本"转向"**遵循指令、有用、诚实、无害**"。这就是对齐（Alignment）问题。

## 2. RLHF 三部曲（InstructGPT，2022.1）

OpenAI 的解决方案分三步，这套流程至今仍是行业标准：

### 第一步：SFT（监督微调）

- 雇佣标注员，针对各种指令**人工撰写理想回答**（约 1.3 万条）
- 用这些数据微调 GPT-3 → 模型初步学会"指令→回答"的格式
- 问题：人工写答案太贵，覆盖不了千变万化的场景

### 第二步：训练奖励模型（RM）

- 让 SFT 模型对同一问题生成**多个不同回答**
- 标注员只需**排序**（A 比 B 好），不用自己写
- 用排序数据训练一个"奖励模型"，学会给任意回答打分

> 💡 **RLHF 的核心洞察**：**判断好坏比写出好答案容易得多**——就像美食评论家不需要会做菜。这一步把昂贵的人工创作变成了廉价的人工评判，使规模化对齐成为可能。

### 第三步：PPO 强化学习

- 把 SFT 模型当作玩家：生成回答 → 奖励模型打分 → 用 PPO 算法调整模型参数，让高分回答更可能出现
- 加一条约束：不许偏离 SFT 模型太远（防止模型"作弊"讨好奖励模型）

**结果震撼业界**：13 亿参数的 InstructGPT，人类偏好评分**超过 1750 亿的 GPT-3**——对齐收益大于 100 倍规模收益。

## 3. ChatGPT：改变世界的三十天（2022.11.30）

OpenAI 把这套技术包装成对话产品（基于 GPT-3.5）：

- **5 天 100 万用户，2 个月 1 亿用户**——史上增长最快的消费级产品
- 对话形式 + 免费 + 效果惊艳 = 公众第一次直接摸到 AI 的能力
- 从此"AI"在大众语境里约等于"大语言模型"

## 4. GPT-4 与开源浪潮（2023）

- **GPT-4（2023.3）**：多模态输入（能看图）、推理大幅提升、通过律师资格考试前 10%
- **LLaMA 泄露事件（2023.3）**：Meta 开源（本意限研究用）的 LLaMA 权重被泄露，全球开发者蜂拥而至，催生出 Alpaca、Vicuna 等微调生态——**开源大模型时代开启**
- **Llama 2（2023.7）**：Meta 正式商用开源，成为开源阵营的基石
- RLHF 的副作用也被认清：讨好用户（谄媚）、过度拒答、模式坍塌（回答趋同）——对齐是把双刃剑

## 5. 这一时期沉淀的范式

```
预训练（读互联网） → SFT（学格式） → RLHF（学偏好）
     能力             听话            讨人喜欢
```

这个三段式至今仍是每个大模型的标准锻造流程，你目录里那本书的第 7 章（后训练）讲的就是它的深化。

## 📌 本课要点

1. GPT-3 不听话是因为训练目标就是"续写"，不是"帮助"——对齐是目标问题
2. RLHF 核心：评判比创作便宜，用奖励模型把人类偏好规模化
3. 13 亿对齐模型胜过 1750 亿未对齐模型——对齐收益可超百倍规模
4. ChatGPT = 对齐技术 + 对话包装，两个月破亿用户，AI 进入大众时代
