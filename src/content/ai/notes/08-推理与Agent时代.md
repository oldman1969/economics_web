# 第八课：推理模型与 Agent 时代（2024–至今）

> 核心问题：预训练的规模红利见顶之后，AI 的下一个增长引擎是什么？

## 1. 背景：预训练撞墙论（2024）

- 到 2024 年，高质量公开文本数据基本被"吃完"（互联网就这么多）
- Scaling Law 依然成立，但**数据成了瓶颈**，单纯堆参数的边际收益递减
- 业界焦虑：预训练之后，增长从哪里来？

答案：**从"训练时计算"转向"推理时计算"**——让模型在回答之前先"想一想"。

## 2. 推理模型：o1 与 R1（2024–2025）

### OpenAI o1（2024.9）

- 核心思想：用**强化学习**训练模型在回答前生成很长的**思维链（Chain-of-Thought）**——自己打草稿、自我检查、错了重来
- 数学、代码、科学竞赛成绩暴涨（AIME 数学竞赛从十几分到七八十分）
- 新的 Scaling Law：**测试时计算量**（思考时间越长）与性能正相关——模型第一次可以"用时间换正确率"

### DeepSeek R1（2025.1）

- 中国团队开源复现并公开了完整方法，震惊全球：
  - **R1-Zero** 证明：纯强化学习（不依赖人工思维链数据），模型能**自发涌现**反思、"等等，我再想想"等推理行为
  - **GRPO** 算法：简化 PPO，省去价值网络，大幅降低 RL 训练成本
- 开源权重 + 极低训练成本传闻，引发美股算力股震荡——效率创新的威慑力

> 💡 范式转变：智能的来源从"**训练时读了多少书**"扩展到"**考试时思考了多久**"。2022 年教模型说话（RLHF），2024 年教模型思考（RL on reasoning）。

## 3. Agent：从"会答"到"会做"（2024–2026）

模型会推理之后，下一个自然问题是：让它**动手**。这就是你目录里那本书的主场：

```
Agent = LLM（大脑）+ 上下文（眼睛）+ 工具（手脚）
```

关键进展：

- **工具使用标准化**：Anthropic 发布 **MCP**（Model Context Protocol，2024.11），给 Agent 接工具定了一套"USB 接口"
- **Coding Agent 爆发**：Claude Code、Cursor 等——代码是 Agent 最好的练兵场（可验证、反馈快、数字原生）
- **Computer Use**：模型直接看屏幕、点鼠标（2024.10 Claude 首发），GUI 成为新的动作空间
- **长任务可靠性**成为主战场：上下文工程（第二课书里第 2 章）、记忆系统、子 Agent 隔离——Harness（脚手架）工程成为模型之外的竞争力

## 4. 多模态与其他前沿（简览）

- **全模态模型（Omni）**：语音、图像、视频统一进一个模型，语音对话延迟逼近人类
- **视频生成**：Sora（2024）等，世界模型的雏形
- **具身智能**：VLA（视觉-语言-动作）模型进机器人

## 5. 站在 2026 年年中回望

七十年浓缩成一条主线：

```
神经元(1943) → 感知机(1957) → 寒冬 → 反向传播(1986)
→ 等数据等算力 → AlexNet(2012) → 注意力(2014) → Transformer(2017)
→ 规模(2020 GPT-3) → 对齐(2022 ChatGPT) → 长上下文工程(2023-25)
→ 推理(2024 o1/R1) → Agent(2025-)
```

不变的规律（苦涩的教训）：**通用方法 + 更多计算，永远胜过人工巧思**。变的只是计算的用法：训练时堆参数 → 推理时堆思考 → Agent 循环里堆行动。

## 📌 本课要点

1. 预训练数据见顶后，增长引擎切换到**测试时计算**（思考换正确率）

3. Agent = LLM + 上下文 + 工具；MCP 标准化工具接口；Coding Agent 率先落地
