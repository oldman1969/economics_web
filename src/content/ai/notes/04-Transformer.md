# 第四课：Transformer——一次讲透（2017）

> 核心问题（也是你最初的问题之一）：**Transformer 到底是什么？**
> 论文：*Attention Is All You Need*，Vaswani 等 8 人，Google，2017 年 6 月。

## 0. 一句话版本

**Transformer = 完全抛弃循环和卷积，只用"自注意力 + 前馈网络"堆叠而成的序列处理器。**

所有现代大模型（GPT、Claude、Gemini、DeepSeek、Kimi……）都是它的变体。这一课是全路线图最重要的一课。

## 1. 它要解决什么问题

回忆第三课的结论：RNN 逐词顺序计算，无法并行、长程信息衰减。Transformer 的设计目标：

- **任意两个词之间直接交互**，不管相距多远（路径长度 = 1）
- **所有词同时计算**，吃满 GPU 的并行能力

## 2. 自注意力（Self-Attention）：每个词看所有词

直觉：读句子"苹果发布了新手机，它很畅销"时，人脑理解"它"指"新手机"，是靠把"它"和前文每个词**比对相关性**。自注意力就是把这个过程数学化。

### 第一步：每个词生成三个向量

每个 token 的嵌入向量，分别乘三个可学习的矩阵，得到：

| 向量 | 含义 | 类比 |
|---|---|---|
| **Q**（Query，查询） | "我想找什么" | 你在搜索框输入的关键词 |
| **K**（Key，键） | "我身上有什么标签" | 网页的标题/索引 |
| **V**（Value，值） | "我实际携带的信息" | 网页的正文内容 |

> 💡 注意力 = **软性的字典查找**：拿 Q 去和所有 K 算匹配度，用匹配度做权重，把所有 V 加权求和取回来。

### 第二步：计算注意力（核心公式）

```
Attention(Q, K, V) = softmax( Q·Kᵀ / √d ) · V
```

逐步拆解：

1. **Q·Kᵀ**：每个词的 Q 和所有词的 K 做点积 → 得到一个 n×n 的"相关性打分表"（n 是序列长度）
2. **÷ √d**：点积随维度增大而变大，除以维度的平方根防止 softmax 饱和（纯工程细节，但论文专门讨论了）
3. **softmax**：每行归一化成概率分布（权重和为 1）→ "我该把百分之多少的注意力分给每个词"
4. **×V**：按权重对所有词的 V 加权求和 → 每个词的新表示 = **全句信息按相关性调和后的精华**

例子：处理"它"这个词时，softmax 后"手机"位置的权重最高，于是"它"的新向量里融进了"手机"的信息——指代消解就这样**自动涌现**了。

### 第三步：多头注意力（Multi-Head）

一组 Q/K/V 只能学一种"看问题的角度"。实际用 **8~96 组并行的注意力头**，各自学不同的关系：

- 有的头关注语法（主谓一致）
- 有的头关注指代（它→手机）
- 有的头关注位置（下一个词）
- 有的头关注语义相关词

拼接所有头的输出再过一个矩阵，得到最终输出。相当于**让一个编委会同时审读，而不是一个编辑**。

## 3. 位置编码：注意力本身"不认顺序"

关键问题：自注意力对输入顺序完全不敏感——"狗咬人"和"人咬狗"算出同样的结果！所以必须**额外注入位置信息**：

- 原论文方案：给每个位置生成一个**正弦/余弦波形向量**（不同频率叠加），加到词嵌入上。模型从波形相位差学会相对距离
- 这个"位置信息如何编码"的问题，后来成了长上下文技术的核心战场（第七课讲 RoPE 时再续）

## 4. 一个完整的 Transformer 块

```
输入嵌入 + 位置编码
    │
 ┌──┴───────────────┐
 │ 多头自注意力       │ ←── 词与词交换信息
 │ + 残差连接 + LayerNorm│
 ├──────────────────┤
 │ 前馈网络 (FFN)     │ ←── 每个词独立地做非线性变换（"思考"）
 │ + 残差连接 + LayerNorm│
 └──────────────────┘
    │ ×N 层堆叠（GPT-3 有 96 层）
```

- **注意力层负责"交流"**（词与词之间），**FFN 负责"加工"**（每个词独立）——有研究认为模型的大部分"知识"存储在 FFN 的权重里
- 残差连接（来自 ResNet）保证百层堆叠时梯度畅通

## 5. 原版结构：编码器 + 解码器

2017 年论文是为机器翻译设计的，有两塔：

- **编码器**：双向自注意力，通读整个源句子（后来的 **BERT** 只用这一半）
- **解码器**：带**掩码**的自注意力（每个位置只能看自己及左边，不能偷看未来）+ 交叉注意力（去查编码器的输出）（后来的 **GPT** 只用这一半，扔掉交叉注意力）

> 💡 **掩码自注意力 = 自回归生成的关键**：预测下一个词时只能看已生成的部分。今天所有生成式大模型都是这个"只能左看"的解码器结构。

## 6. 为什么它是历史级的

| 维度 | RNN/LSTM | Transformer |
|---|---|---|
| 长程依赖路径 | O(n)（信息逐站传递） | **O(1)**（任意两词直连） |
| 训练并行度 | 无法并行（逐词） | **完全并行**（整句矩阵运算） |
| 每层计算量 | O(n) | O(n²) ← 唯一的代价 |

O(n²) 这个代价就是伏笔：**序列长度翻倍，注意力计算量翻四倍**。当 n = 一百万时，这张 n×n 的表有一万亿个格子。第七课的"为什么上下文卡在 1M"，根子全在这里。

## 7. 后来的演化脉络

- **2018**：GPT-1（只用解码器做生成）、BERT（只用编码器做理解）
- **2019–2020**：GPT-2/3 证明解码器路线 + 规模 = 通用能力（第五课）
- **效率改良**：FlashAttention、稀疏注意力、RoPE、GQA……（第七课）
- **架构微调**：Pre-Norm、SwiGLU、MoE——今天的大模型骨架仍是 2017 年的它

## 📌 本课要点

1. 自注意力 = 用 Q 查 K 得权重、加权取 V 的**软性检索**，任意两词直接交互
2. 多头 = 多角度并行审读；位置编码补顺序；残差 + LayerNorm 保梯度
3. GPT 系 = 带掩码的解码器（只能左看）；BERT = 双向编码器
4. 全面并行 + 长程直连，换来训练效率革命；代价是 O(n²)——1M 上下文之难由此而来

## 关键公式收藏

```
Attention(Q,K,V) = softmax(QKᵀ/√dₖ)V
MultiHead = Concat(head₁...headₕ)Wᴼ
FFN(x) = max(0, xW₁ + b₁)W₂ + b₂   （原版；现代用 SwiGLU）
```
