## 1. 核心观点：四条线并行发展，最后汇聚

你已学的文本线：

```
文本: 神经元(1943) → RNN/LSTM → Transformer(2017) → GPT(2020) → ChatGPT(2022)
```

但与此同时，另外三条线也在各自演进：

```
图像: SIFT(1999) → CNN(2012) → ResNet(2015) → ViT(2020) → CLIP(2021) → VLM(2023)
语音: GMM-HMM(1990s) → DNN(2012) → LSTM → Transformer → Whisper(2022) → 全双工(2024)
视频: 光流(传统) → 3D CNN(2014) → Video Transformer → Sora(2024)
```

**关键洞察**：这三条线在 2020 年之前基本**各走各的**——做图像的不管语音，做语音的不管视频。直到 **Transformer 成为万能底座 + 对比学习（CLIP）解决了"对齐"**，四条线才开始汇聚成"一个模型处理所有模态"。

> 💡 为什么 2023 年突然爆发 GPT-4V、Gemini 等多模态模型？因为**图像、语音、视频各自的技术栈在 2020 年前后都已成熟**，只差一个"把它们拼起来"的框架——而 CLIP 提供了这个框架。

## 2. 图像线：从像素到语义

### 2.1 传统时代（1950s–1990s）：手工设计特征

早期图像处理靠**人工设计的特征提取器**，最有名的是：

- **SIFT（1999，David Lowe）**：尺度不变特征变换，检测"关键点"并描述其局部特征——旋转、缩放、光照变化下都稳定
- **HOG（2005）**：梯度方向直方图，行人检测的经典特征

**核心问题**：这些特征是**人手工设计的**，换个任务就得重新设计，且表达能力有限。这正是"苦涩的教训"在图像领域的版本——手工特征的天花板很低。

### 2.2 CNN 崛起（1998–2015）：从手工到自动学习

你已经在 [deep-dives/01 CNN](../ai_theory/deep-dives/01-CNN深度解剖.md) 学过这条线：

```
LeNet(1998) → AlexNet(2012) → VGG(2014) → ResNet(2015，超越人类)
```

CNN 用**自动学习的卷积核**取代了手工特征——"检测边缘"这个曾经要人手工设计的东西，现在模型自己学。

### 2.3 从分类到理解（2014–2020）：检测、分割

图像分类（整张图是什么）只是第一步，真正的"理解"需要更细的粒度：

| 任务 | 问题 | 代表工作 |
|------|------|----------|
| 物体检测 | 图里有哪些物体、在哪？ | R-CNN(2014) → Faster R-CNN(2015) → YOLO |
| 语义分割 | 每个像素属于什么？ | U-Net(2015) → Mask R-CNN(2017) |
| 实例分割 | 每个物体实例分开 | Mask R-CNN(2017) |

### 2.4 ViT（2020）：Transformer 进视觉

**关键转折**。之前图像是 CNN 的天下，但 Google 的 ViT（Vision Transformer）证明：**把图像切成 16×16 的小块（patch），每个 patch 当作一个"token"，直接喂给 Transformer，也能达到甚至超越 CNN**。

```
图像 → 切成 16×16 的 patch → 每个 patch 展平成向量 → [CLS] token + 位置编码 → Transformer
```

> 💡 ViT 的意义：**图像和文本终于可以用同一个架构（Transformer）处理了**。这是多模态统一的前提——之前 CNN（图像）和 Transformer（文本）是两套东西，现在都是 Transformer。

### 2.5 CLIP（2021）：图文对齐

你刚学过的 [CLIP 深度解剖](../deep-dives/01-CLIP深度解剖.md)：用对比学习把图像和文字拉进同一向量空间。这是"对齐"的鼻祖。

### 2.6 VLM 时代（2023+）：看图说话

LLaVA、GPT-4V、Qwen-VL——把 CLIP 的视觉编码器 + LLM 拼起来，模型既能看又能说。

## 3. 语音线：从声波到对话

### 3.1 传统时代（1990s–2010）：GMM-HMM

语音识别最经典的框架是 **GMM-HMM**（高斯混合模型 + 隐马尔可夫模型）：

- **HMM** 建模"音素序列"（语音的基本单元），处理时序
- **GMM** 建模"每个音素听起来像什么"（声学特征 → 概率）

这套系统统治了语音识别 20 年，但极其复杂——需要音素标注、发音词典、语言模型等多个模块手工拼装。

### 3.2 深度学习（2012–2017）：DNN → LSTM

- **DNN-HMM（2012）**：用神经网络取代 GMM 做声学建模，错误率大幅下降
- **LSTM（你学过 deep-dives/02）**：擅长时序，成为语音识别的标准

### 3.3 端到端与 Whisper（2017–2022）

- **2017+**：Transformer 引入语音，出现**端到端 ASR**——不再需要音素标注、发音词典，直接从音频到文字
- **Whisper（2022，OpenAI）**：用 68 万小时弱监督音频训练的通用 ASR，多语言、抗噪，成为工业标准

### 3.4 语音合成（TTS）的并行线

| 阶段 | 代表 | 特点 |
|------|------|------|
| 拼接合成 | 早期 | 拼接录音片段，机械感强 |
| 参数合成 | HMM | 统计参数，自然度一般 |
| 神经 TTS | WaveNet(2016)、Tacotron(2017) | 端到端神经合成，自然度飞跃 |
| 全双工 | Moshi(2024)、GPT-Live(2026) | 边听边说，取消"轮流"假设 |

> 你已在 [learn_agent/09](../learn_agent/09-多模态与实时交互.md) 学过语音的三种架构范式（级联→Omni→全双工）。

## 4. 视频线：从帧到时空

### 4.1 传统时代：光流

视频 = 一系列图像帧。传统方法靠**光流（Optical Flow）**估计像素运动——计算相邻帧之间"每个像素往哪动"。

### 4.2 3D CNN（2014–2017）：加入时间维度

把 2D 卷积核变成 3D（宽×高×时间），直接处理视频片段：

```
C3D(2014) → I3D(2017，把 2D CNN 膨胀成 3D)
```

### 4.3 Video Transformer（2020s）

和 ViT 同思路：把视频切成"时空块"，喂给 Transformer。

### 4.4 视频生成（2024）：Sora 时刻

你已在 [deep-dives/15 扩散模型](../ai_theory/deep-dives/15-扩散模型.md) 学过扩散模型的数学。**Sora（2024）** 把它扩展到视频——用扩散模型在时空维度生成连贯视频。

> 💡 视频发展史相对最短，因为视频本质是"图像 + 时间"，很多技术直接复用图像线的成果。

## 5. 融合线：从独立到统一

这是理解"多模态大模型怎么来的"最关键的一条线：

### 5.1 早期（2010s）：各自处理 + 特征拼接

图像用 CNN、文本用 RNN、语音用 LSTM，各自提取特征，最后拼在一起喂给一个分类器。**模态之间没有真正的"理解"**，只是特征层面的拼接。

### 5.2 联合嵌入（2021）：CLIP 对齐

CLIP 第一次把图像和文本**映射到同一向量空间**，让"狗"和狗的照片在数学上"靠在一起"。这是"对齐"的突破。

### 5.3 端到端统一（2023）：GPT-4V、Gemini

不再"各自编码 + 拼接"，而是**一个 Transformer 同时吃下图像 token 和文本 token**：

```
[图像 patch token] [文本 token] → 一个 Transformer → 输出
```

- **GPT-4V（2023）**：OpenAI 的多模态 GPT-4
- **Gemini（2023）**：Google 原生多模态
- **Qwen-VL、InternVL、Pixtral**：开源阵营

### 5.4 Omni 全模态（2024+）：GPT-4o

从"图文"扩展到"语音+图像+文本"全模态，一个模型处理所有输入输出。你已在 [learn_agent/09](../learn_agent/09-多模态与实时交互.md) 学过 Omni 与全双工的演进。

## 6. 时间线对照表：四条线怎么汇聚

这是本篇的核心——看清四条线如何并行发展、最后汇聚：

| 年份 | 文本线 | 图像线 | 语音线 | 视频线 |
|------|--------|--------|--------|--------|
| 1998 | — | LeNet | — | — |
| 1999 | — | **SIFT** | — | — |
| 2012 | — | **AlexNet**（DL 爆发） | DNN-HMM | — |
| 2014 | Seq2Seq | R-CNN | LSTM | C3D |
| 2015 | 注意力 | **ResNet**（超人类） | — | — |
| 2016 | — | — | WaveNet | — |
| 2017 | **Transformer** | Faster/Mask R-CNN | Tacotron | I3D |
| 2020 | **GPT-3** | **ViT** | — | — |
| 2021 | — | **CLIP**（对齐） | — | — |
| 2022 | **ChatGPT** | — | **Whisper** | — |
| 2023 | GPT-4 | **GPT-4V / LLaVA** | — | — |
| 2024 | o1/R1 | Qwen-VL | **Moshi 全双工** | **Sora** |

**读这张表的关键**：

1. **2017 之前**：四条线几乎零交集，各自发展
2. **2017 Transformer** 出现，但还没跨模态
3. **2020 ViT** 让图像也用 Transformer——架构开始统一
4. **2021 CLIP** 解决"对齐"——跨模态的钥匙
5. **2022-2024**：四条线全面汇聚，多模态大模型爆发

> 💡 **一句话总结**：多模态不是"发明了新技术"，而是**Transformer（统一架构）+ CLIP（解决对齐）**这两个关键突破，把四条独立发展了 30 年的线，终于拼到了一起。

## 📌 本篇要点

1. 文本/图像/语音/视频四条线**各自独立发展了 30 年**，2020s 才汇聚
2. 图像线：SIFT(手工) → CNN(自动学习) → ViT(Transformer) → CLIP(对齐) → VLM
3. 语音线：GMM-HMM → DNN/LSTM → 端到端 Transformer → Whisper → 全双工
4. 视频线：光流 → 3D CNN → Video Transformer → Sora
5. 融合线：各自拼接 → 联合嵌入(CLIP) → 端到端统一(GPT-4V) → Omni
6. **两个关键突破**让汇聚成为可能：Transformer（统一架构）+ CLIP（解决对齐）
