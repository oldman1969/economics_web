## 1. 从"位置序号"到"旋转角度"

原版正弦位置编码是**绝对值**：位 0 是 [sin(0), cos(0), sin(0/scale), ...]，位 100 完全不同。

RoPE（Rotary Position Embedding，苏剑林，2021）的核心思想：**不编码位置是什么，而编码两个位置之间的相对距离**。怎么做到？ —— **把 token 向量在子空间里旋转，旋转的角度正比于它的位置**。

这样，token_i 和 token_j 的点积就自动包含了它们之间的相对位置差（旋转角之差）——不再依赖绝对位置。

## 2. RoPE 的数学：把位置编码注入 Q 和 K

### 2.1 二维旋转矩阵

在二维平面上，把向量逆时针旋转 θ 角：

```
R(θ) = [cos θ, -sin θ]
       [sin θ,  cos θ]

旋转后的 v' = R(θ) · v
```

### 2.2 分维度旋转（RoPE 的核心）

把 Q 和 K 的 d 维向量**两两分组**（d/2 对），每对用不同频率旋转：

```
对第 i 对 (维度 2i 和 2i+1):
    θ_i = pos / (10000^{2i/d})

    Q 的这对 → 旋转 pos 个单位  —— R(θ_i)ᵖᵒˢ
    K 的这对 → 旋转 pos 个单位  —— R(θ_i)ᵖᵒˢ
```

结果：Q_pos · K_pos' 里包含的旋转量是 **R(m - n)**（位置差）——纯粹的相对位置！

### 2.3 频率分布

```
高频 (i 大, θ ≈ π/2 ~ π):     捕捉相邻关系 (< 4 个位置)
中频 (i 中等, θ ≈ 0.01~0.1):  捕捉段落级关系 (几十个位置)
低频 (i 小, θ ≈ 10^{-4}~10^{-5}): 捕捉全局位置 (> 1000 个位置)
```

> ⚠️ **外推崩溃的根源就在这里**：训练的序列长度是 4096 → 对最低频，见过的最大旋转角度是 `4096 × 10^{-5} = 0.04` 弧度（约 2.3°）。但如果来一个 100K 的序列，最低频的旋转角变成 `100000 × 10^{-5} = 1.0` 弧度（57°）——模型从未见过这个角度下的向量关系！

## 3. 手算：两个位置的 RoPE 旋转

设定 d=4（2 对），base=10000，位置 m=0, n=3。

```
频率:
i=0: θ₀ = 1 / 10000^{0/4} = 1 / 1 = 1.000
i=1: θ₁ = 1 / 10000^{2/4} = 1 / 100 = 0.010

位置 m=0 的旋转角: [0×1.000, 0×0.010] = [0, 0]
                    （位置 0 不旋转，是基准）

位置 n=3 的旋转角: [3×1.000, 3×0.010] = [3.000, 0.030]

对于 x = [1, 2, 3, 4]（4 维）在位置 n=3:

第 0 对 (维 0-1): [1, 2] 旋转 3.000 弧度
  cos(3.000)=-0.990, sin(3.000)=0.141
  [1×(-0.990) - 2×0.141, 1×0.141 + 2×(-0.990)]
  = [-0.990 - 0.282, 0.141 - 1.980]
  = [-1.272, -1.839]

第 1 对 (维 2-3): [3, 4] 旋转 0.030 弧度
  cos(0.030)=1.000, sin(0.030)=0.030  ← 几乎不转！
  [3×1.000 - 4×0.030, 3×0.030 + 4×1.000]
  = [3 - 0.12, 0.09 + 4]
  = [2.880, 4.090]

位置 n=3 的 RoPE 编码后: [-1.272, -1.839, 2.880, 4.090]
```

> 💡 观察：高频对转了 3 弧度（~172°）→ 几乎翻转了向量 → 相邻 token 可以通过高频旋转来区分。低频对才转了 0.03 弧度（~1.7°）→ 几乎没变化 → 远距离 token 之间通过低频缓慢旋转来保持联系。

## 4. 频率分治：为什么外推会炸

对于训练的 4096 序列长度，最低频的最大旋转角：

```
θ_min × max_pos = (1 / 10000^{2×(d/2-1)/d}) × 4096

以 d=128 为例:
θ_min = 1 / 10000^{126/128} = 1 / 10000^{0.984} ≈ 1 / 7943 ≈ 0.000126
max_angle = 0.000126 × 4096 ≈ 0.516 弧度 = 29.5°
```

外推到 128K：

```
max_angle = 0.000126 × 131072 ≈ 16.5 弧度 ≈ 945° ← 转了两圈半多！
```

模型在训练中从没见过 K 向量被转过 16 弧度——它完全不知道该怎么做注意力。注意力分布变成随机噪声。

## 5. 位置插值：把没见过的位置"拉"回来

### 方案一：线性位置插值（PI，2023）

```
把位置 idx → scale × idx（scale < 1）

128K → scale=4096/131072=1/32 → 位置 131072 映射到 4096
```

效果：最低频的旋转角度回到训练范围内。代价：高频本来转 0.1 弧度的现在只转 0.003 → 局部 token 之间的区分度下降。

### 方案二：NTK-aware scaling 和 YaRN（2023）

解决线性插值的"高频模糊"问题：**分频段缩放**——高频按 1:1（不应压缩），低频按 1:32（应压缩），中间平滑过渡。

```
λ_i = 与波长相关的缩放因子，波长短于训练长度的高频不压缩
```

这就是为什么模型版本更新时上下文窗口能原地翻倍——**YaRN 方法让 4K 模型仅需 0.1% 微调数据就适配 128K**。

## 6. MATLAB：RoPE 实现与外推实验

```matlab
% ============================================================
% ROPE_DEMO.m
% RoPE 实现 + 外推崩溃演示
% ============================================================
clear; clc;

fprintf('=== RoPE 旋转位置编码 ===\n\n');

%% 参数
d = 64;           % 维度
base = 10000;
max_train_len = 4096;
max_test_len = 32768;  % 外推 8 倍

%% 构造 RoPE 频率
freqs = 1 ./ (base .^ ((0:2:d-2) / d));  % 1×32 (每对一个频率)

%% 给定位置, 生成的 RoPE 旋转矩阵 (以 cos/sin 形式)
rope_cache_train = precompute_rope(max_train_len, freqs, d);
rope_cache_test  = precompute_rope(max_test_len,  freqs, d);

%% 测试: 同一个 token 向量, 在训练范围 vs 外推范围
% 随机一个 token 的 Q 向量
rng(42);
q = randn(d, 1) * 0.1;

% 在训练最大位置 (pos=4096) 旋转
q_4096 = apply_rope(q, 4096, rope_cache_train);

% 在外推位置 (pos=32768) 旋转
q_32768 = apply_rope(q, 32768, rope_cache_test);

% 比较两个旋转后的向量
cos_sim = dot(q_4096, q_32768) / (norm(q_4096) * norm(q_32768));
fprintf('训练位置 4096 vs 外推位置 32768 旋转后余弦相似度: %.4f\n', cos_sim);
fprintf('→ 如果接近 0 或随机, 说明位置编码完全变了 (模型崩溃)\n');

%% 位置插值方案: scale=4096/32768=0.125
fprintf('\n--- 位置插值 (PI) ---\n');
scale = max_train_len / max_test_len;
pos_scaled = round(32768 * scale);
q_scaled = apply_rope(q, pos_scaled, rope_cache_train);

cos_sim_pi = dot(q_4096, q_scaled) / (norm(q_4096) * norm(q_scaled));
fprintf('外推+PI 缩放后与训练 4096 的相似度: %.4f\n', cos_sim_pi);
fprintf('→ PI 把旋转"拉回"训练范围内\n');

%% 辅助函数
function cache = precompute_rope(max_len, freqs, d)
    pos = (0:max_len-1)';
    angles = pos * freqs;  % (max_len × d/2)
    cache.cos = cos(angles);
    cache.sin = sin(angles);
end

function x_rot = apply_rope(x, pos, cache)
    % x: d×1, pos: 1-indexed 位置
    d = length(x);
    x_rot = x;
    for i = 1:2:d-1
        pair_idx = (i+1)/2;
        c = cache.cos(pos+1, pair_idx);
        s = cache.sin(pos+1, pair_idx);
        x1 = x(i); x2 = x(i+1);
        x_rot(i)   = x1 * c - x2 * s;
        x_rot(i+1) = x1 * s + x2 * c;
    end
end
```

## 7. 其他方案：ALiBi、NoPE

| 方案 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| RoPE | 旋转位置编码，相对位置 = 旋转角差 | 强理论性，相对位置信息丰富 | 外推需插值 |
| ALiBi | 不给位置编码，直接给注意力打分加距离偏置 | 天然外推，无需插值 | 相对位置信息不如 RoPE 丰富 |
| NoPE | 完全不要位置编码 | 简洁，靠因果掩码自然学习顺序 | 长程效果差，未被大规模验证 |

> ALiBi 的注意力偏置：`score_ij = Q_i·K_j - m × |i-j|`，m 是头特定的标量。距离越远扣分越多 → 接近的词天然"联系更紧"——这个朴素的先验就是 ALiBi 零外推损耗的来源。

## 📌 本章要点

1. RoPE 把位置信息编码为 **Q/K 向量在 2D 子空间的旋转**，旋转角正比于位置
2. 高频（波长短）管局部区分，低频（波长长）管全局依赖
3. 外推失败是因为低频旋转角度超出训练范围
4. YaRN 分频段插值：高频不压（保持局部分辨率），低频内缩（回训练域）
5. 这是"模型 4K 上下文 0.1% 微调就能到 128K"的幕后技术
