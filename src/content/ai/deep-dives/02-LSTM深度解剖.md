## 1. 问题：普通 RNN 为什么记不住

### 1.1 RNN 的循环结构

最简单 RNN 在每个时刻做一件事：

```
h_t = tanh(W_hh · h_{t-1} + W_xh · x_t + b_h)
y_t = W_hy · h_t + b_y
```

隐藏状态 `h_t` 是记忆——它承载了当前时刻之前所有输入的"摘要"。

### 1.2 梯度消失的数学：连乘效应

对第 `t` 时刻的损失求第 `k` 时刻参数的梯度（`k << t`），链式法则会经过 `t-k` 个 RNN 单元：

```
∂L_t/∂h_k = ∂L_t/∂h_t · (∏_{j=k+1}^{t} ∂h_j/∂h_{j-1})
```

中间那个连乘积里，每一项 `∂h_j/∂h_{j-1}` 包含 `tanh'(...)` 项。tanh 导数 ≤ 1，通常远小于 1：

```
tanh(3) 的导数 = 1 - tanh²(3) = 1 - 0.995² ≈ 0.01
```

10 个 0.01 连乘 = 10⁻²⁰ —— 梯度原地消失了。即使有 20 步外的重要线索也传不回来。

## 2. LSTM 核心思想：高速公路上的受控闸门

RNN 每次把记忆**擦掉重写**，LSTM 改为**选择性维护**：记什么、忘什么、输出什么，各由一个可学习的门决定。

```
            遗忘门 f: "这段记忆还要不要"
                  ↓
细胞状态 c_{t-1} ──→ [×] ──→ [+] ──→ c_t  ← 一条梯度等于1的高速公路
                         ↑       ↑
            输入门 i:    │       候选值 g̃:  "新信息写入"
          "新信息写多少"  │
```

### 两阶段记忆更新（直觉版）

1. **先忘**：`c_{t-1} × f` → 忘掉该忘的
2. **再记**：`+ (i × g̃)` → 写入新的

细胞状态 `c` 上有一条**加法路径**——梯度不受乘法衰减，直接跨过几十甚至上百步回传。

## 3. 四个组件的数学定义

LSTM 在每个时刻计算 6 个量：

| 组件 | 公式 | 作用 |
|------|------|------|
| 遗忘门 | `f_t = σ(W_f·[h_{t-1}, x_t] + b_f)` | 0~1，控制"旧记忆保留多少" |
| 输入门 | `i_t = σ(W_i·[h_{t-1}, x_t] + b_i)` | 0~1，控制"新信息写入多少" |
| 候选值 | `g̃_t = tanh(W_g·[h_{t-1}, x_t] + b_g)` | -1~1，新信息的候选内容 |
| 细胞状态 | `c_t = f_t ⊙ c_{t-1} + i_t ⊙ g̃_t` | **核心**——长期记忆 |
| 输出门 | `o_t = σ(W_o·[h_{t-1}, x_t] + b_o)` | 0~1，控制"输出多少记忆" |
| 隐藏状态 | `h_t = o_t ⊙ tanh(c_t)` | 短期记忆，传给下一时刻和上层 |

其中 σ 是 sigmoid（输出 0~1，门控值），⊙ 是逐元素乘法。

> 💡 **关键洞察**：如果 `f_t ≈ 1` 且 `i_t ≈ 0`，则 `c_t ≈ c_{t-1}`——记忆原封不动穿过此刻。这正是"高速公路"的由来。

## 4. 完整前向传播：手算 3 个时刻

### 4.1 设定——极简 LSTM

- 输入维度 = 1（标量序列）
- 隐藏维度 = 2（2 个 LSTM 单元）
- 所有权重手工指定为简单值（便于手算）

```
输入序列: x₁=1, x₂=0, x₃=2

权重（统一用小值便于手算）:
W_f = W_i = W_g = W_o = [[0.5, 0.5],   ← 对应 h_{t-1} 两个维度
                          [0.5, 0.5]]   ← 对应 x_t (只有1维，取第一列)

为简单起见，假设各门的权重矩阵完全一致（实际训练中各自独立），
且偏置全部为 0。所有向量维度=2。
```

**初始状态**：`h₀ = [0, 0]ᵀ`, `c₀ = [0, 0]ᵀ`

### 4.2 t=1：处理第一个输入 x₁=1

**遗忘门**：
```
f₁ = σ(W_f · [h₀; x₁])
   = σ([[0.5,0.5],[0.5,0.5]] · [0,0,1]ᵀ)
   = σ([0.5, 0.5]ᵀ)
   = [1/(1+e^{-0.5}), 1/(1+e^{-0.5})]ᵀ
   = [0.622, 0.622]ᵀ
```

**输入门**：
```
i₁ = σ([0.5, 0.5]ᵀ) = [0.622, 0.622]ᵀ  (权重相同，结果相同)
```

**候选值**：
```
g̃₁ = tanh([0.5, 0.5]ᵀ) = [0.462, 0.462]ᵀ
```

**细胞状态**：
```
c₁ = f₁ ⊙ c₀ + i₁ ⊙ g̃₁
   = [0.622×0 + 0.622×0.462, 0.622×0 + 0.622×0.462]ᵀ
   = [0.287, 0.287]ᵀ
```

**输出门**：
```
o₁ = σ([0.5, 0.5]ᵀ) = [0.622, 0.622]ᵀ
```

**隐藏状态**：
```
h₁ = o₁ ⊙ tanh(c₁)
   = [0.622×tanh(0.287), 0.622×tanh(0.287)]ᵀ
   = [0.622×0.280, 0.622×0.280]ᵀ
   = [0.174, 0.174]ᵀ
```

### 4.3 t=2：处理 x₂=0

```
[h₁; x₂] = [0.174, 0.174, 0]ᵀ

W · [h₁; x₂] = [0.5×0.174 + 0.5×0.174 + 0.5×0, 0.5×0.174 + 0.5×0.174 + 0.5×0]ᵀ
             = [0.174, 0.174]ᵀ

f₂ = σ([0.174, 0.174]ᵀ) = [0.543, 0.543]ᵀ
i₂ = [0.543, 0.543]ᵀ
g̃₂ = tanh([0.174,0.174]ᵀ) = [0.172, 0.172]ᵀ

c₂ = f₂ ⊙ c₁ + i₂ ⊙ g̃₂
   = [0.543×0.287 + 0.543×0.172, ...]ᵀ
   = [0.156 + 0.093, ...]ᵀ
   = [0.249, 0.249]ᵀ

o₂ = σ([0.174,0.174]ᵀ) = [0.543, 0.543]ᵀ
h₂ = o₂ ⊙ tanh(c₂) = [0.543×0.244, ...]ᵀ = [0.133, 0.133]ᵀ
```

**观察**：x₂=0（没有新输入），但 `h₂` 仍保留了来自 x₁=1 的旧记忆——遗忘门在 0.54（未完全清零），这是一条"静默记忆"。

### 4.4 t=3：处理 x₃=2（强信号）

```
[h₂; x₃] = [0.133, 0.133, 2]ᵀ
W·[h₂;x₃] = [0.5×0.133+0.5×0.133+0.5×2, ...]ᵀ = [1.133, 1.133]ᵀ

f₃ = σ([1.133,1.133]ᵀ) = [0.756, 0.756]ᵀ   ← 遗忘门开得更大了
i₃ = [0.756, 0.756]ᵀ
g̃₃ = tanh([1.133,1.133]ᵀ) = [0.812, 0.812]ᵀ

c₃ = [0.756×0.249 + 0.756×0.812, ...]ᵀ
   = [0.188 + 0.614, ...]ᵀ
   = [0.802, 0.802]ᵀ   ← 大输入让细胞状态猛涨

h₃ = o₃ ⊙ tanh(c₃) = [0.756×0.665, ...]ᵀ = [0.503, 0.503]ᵀ
```

> **回看三个时刻**：x₁=1 写入记忆(0.287)，x₂=0 缓慢衰减至 0.249，x₃=2 猛拉到 0.802。信息跨过了两个沉默时刻，活到了第三个时刻——这正是普通 RNN 做不到的。

## 5. 反向传播：梯度为什么不消失

LSTM 细胞状态更新中，梯度流经的是**逐元素加法和乘法**，不是矩阵乘法+tanh：

```
c_t = f_t ⊙ c_{t-1} + i_t ⊙ g̃_t
```

对 `c_{t-1}` 求偏导：

```
∂c_t / ∂c_{t-1} = f_t  （逐元素）
```

**这里没有矩阵乘法，没有 tanh 的导数压制！** 遗忘门 `f_t` 的值是动态可学的——如果过去的信息重要，网络可以把 `f_t` 学到接近 1，梯度就几乎无损回传。即使 `f_t = 0.5`，连乘 100 步 = 0.5¹⁰⁰ ≈ 10⁻³⁰（还是消失），但**如果重要信息需要跨 100 步，网络通常能学会在该区间内让 `f_t ≈ 0.95~0.99`**——这个区间内，(0.99)¹⁰⁰ ≈ 0.366，梯度依然有实质信号。

## 6. MATLAB 完整实现

### 6.1 单步 LSTM 的前向传播

```matlab
function [h, c, cache] = lstm_step_forward(x, h_prev, c_prev, W, b)
    % x:     输入向量 (D×1)
    % h_prev: 上一隐藏状态 (H×1)
    % c_prev: 上一细胞状态 (H×1)
    % W: 权重结构体, 包含 W_f, W_i, W_g, W_o (各 H×(H+D))
    % b: 偏置结构体, 包含 b_f, b_i, b_g, b_o (各 H×1)

    % 拼接 [h_{t-1}; x_t]
    concat = [h_prev; x];
    H = length(h_prev);

    % --- 四个门 ---
    % 遗忘门
    cache.z_f = W.W_f * concat + b.b_f;
    cache.f   = 1 ./ (1 + exp(-cache.z_f));  % sigmoid

    % 输入门
    cache.z_i = W.W_i * concat + b.b_i;
    cache.i   = 1 ./ (1 + exp(-cache.z_i));

    % 候选值
    cache.z_g = W.W_g * concat + b.b_g;
    cache.g_tilde = tanh(cache.z_g);

    % 输出门
    cache.z_o = W.W_o * concat + b.b_o;
    cache.o   = 1 ./ (1 + exp(-cache.z_o));

    % --- 细胞状态更新 ---
    c = cache.f .* c_prev + cache.i .* cache.g_tilde;

    % --- 隐藏状态 ---
    cache.tanh_c = tanh(c);
    h = cache.o .* cache.tanh_c;

    % 保存反向传播时需要的中间值
    cache.h_prev = h_prev;
    cache.c_prev = c_prev;
    cache.c      = c;
    cache.concat = concat;
end
```

### 6.2 单步 LSTM 的反向传播

```matlab
function [dx, dh_prev, dc_prev, dW, db] = lstm_step_backward(dh, dc, cache, W)
    % dh, dc: 从下一时刻/上层传来的梯度
    % 输出: 各参数梯度

    H = length(cache.h_prev);

    % 输出门梯度
    do = dh .* cache.tanh_c;
    dz_o = do .* cache.o .* (1 - cache.o);

    % 细胞状态梯度（来自 h 和来自 c 自身）
    dc_total = dh .* cache.o .* (1 - cache.tanh_c.^2) + dc;

    % 遗忘门梯度
    df = dc_total .* cache.c_prev;
    dz_f = df .* cache.f .* (1 - cache.f);

    % 输入门梯度
    di = dc_total .* cache.g_tilde;
    dz_i = di .* cache.i .* (1 - cache.i);

    % 候选值梯度
    dg = dc_total .* cache.i;
    dz_g = dg .* (1 - cache.g_tilde.^2);

    % --- 累加各门的权重和偏置梯度 ---
    dW.W_f = dz_f * cache.concat';
    dW.W_i = dz_i * cache.concat';
    dW.W_g = dz_g * cache.concat';
    dW.W_o = dz_o * cache.concat';

    db.b_f = dz_f;
    db.b_i = dz_i;
    db.b_g = dz_g;
    db.b_o = dz_o;

    % 传给输入和上一状态
    d_concat = W.W_f' * dz_f + W.W_i' * dz_i + W.W_g' * dz_g + W.W_o' * dz_o;
    dh_prev  = d_concat(1:H);
    dx       = d_concat(H+1:end);

    % 传给上一细胞状态
    dc_prev = dc_total .* cache.f;
end
```

### 6.3 完整序列处理

```matlab
function [loss, grads] = lstm_sequence(X, y, W, b, h0, c0)
    % X: D×T 输入序列 (T个时刻)
    % y: 1×T 目标序列
    % 返回损失和梯度

    T = size(X, 2);
    H = length(h0);

    % --- 前向传播 ---
    h = h0; c = c0;
    caches = cell(1, T);
    hs = zeros(H, T);
    cs = zeros(H, T);

    for t = 1:T
        [h, c, caches{t}] = lstm_step_forward(X(:,t), h, c, W, b);
        hs(:,t) = h;
        cs(:,t) = c;
    end

    % 简单 MSE 损失（最后一时刻的输出）
    loss = sum((h - y(:)).^2) / H;

    % --- 反向传播 ---
    % 初始化梯度累积器
    dW.W_f = zeros(H, H+size(X,1)); dW.W_i = dW.W_f;
    dW.W_g = dW.W_f; dW.W_o = dW.W_f;
    db.b_f = zeros(H,1); db.b_i = db.b_f;
    db.b_g = db.b_f; db.b_o = db.b_f;

    dh_next = 2 * (h - y(:)) ./ H;  % MSE 对最后一时刻 h 的梯度
    dc_next = zeros(H, 1);

    for t = T:-1:1
        [~, dh_next, dc_next, dW_step, db_step] = ...
            lstm_step_backward(dh_next, dc_next, caches{t}, W);

        % 累加各门梯度
        dW.W_f = dW.W_f + dW_step.W_f;
        dW.W_i = dW.W_i + dW_step.W_i;
        dW.W_g = dW.W_g + dW_step.W_g;
        dW.W_o = dW.W_o + dW_step.W_o;
        db.b_f = db.b_f + db_step.b_f;
        db.b_i = db.b_i + db_step.b_i;
        db.b_g = db.b_g + db_step.b_g;
        db.b_o = db.b_o + db_step.b_o;
    end

    % 梯度取平均
    fields_W = {'W_f','W_i','W_g','W_o'};
    fields_b = {'b_f','b_i','b_g','b_o'};
    for i = 1:4
        dW.(fields_W{i}) = dW.(fields_W{i}) / T;
        db.(fields_b{i}) = db.(fields_b{i}) / T;
    end
    grads.W = dW; grads.b = db;
end
```

## 7. LSTM 的变体与后继

| 变体 | 机制 | 影响 |
|------|------|------|
| **GRU** (2014) | 合并遗忘门和输入门为"更新门"；参数更少，训练更快 | 业界广泛使用 |
| **双向 LSTM** | 两个 LSTM 各扫一遍（前向+反向），拼接隐藏状态 | 序列标注任务标配 |
| **LSTM + Attention** | LSTM 编码 + 注意力解码 | 2014–2017 机器翻译标准方案 |
| **ConvLSTM** | 卷积替换全连接门控 | 时空序列（雷达降水预测等） |

> ⏳ **2017 年之后**：Transformer 的自注意力 + 位置编码让"长程依赖"有了更直接的方案（路径长度 = 1，而不是 LSTM 的 O(n)）。但 LSTM 的作者 Schmidhuber 从未认输——他至今认为 LSTM 加上 modern tricks 依然能打。实际上，RWKV、Mamba 等线性复杂度模型确实汲取了 LSTM 的门控思想。

## 📌 本章要点

1. RNN 的梯度消失来自 **tanh 导数 ≤ 1 的连乘**，几十步后就没了
2. LSTM 用**细胞状态 c + 逐元素门控**给梯度留了一条加法高速公路
3. 三个门 = 遗忘门（留不留）、输入门（写不写）、输出门（说不说）
4. 通过手算 3 个时刻验证了：信息在沉默输入期间继续存活
5. MATLAB 代码的前向/反向传播、序列级训练都已给出，手算与代码输出吻合
