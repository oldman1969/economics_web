## 1. 强化学习的问题设定：MDP

智能体（agent）和环境（environment）反复交互：

```
状态 s → [智能体选动作 a] → 环境返回: 新状态 s' + 奖励 r → 重复
```

马尔可夫决策过程（MDP）由四元组定义：

| 元素 | 含义 | 例子（下棋） |
|------|------|------|
| 状态 S | 环境的所有可能状态 | 棋盘布局 |
| 动作 A | 智能体可选动作 | 某步走法 |
| 转移 P(s'|s,a) | 做 a 后到 s' 的概率 | 对手的应对 |
| 奖励 R(s,a) | 即时回报 | 吃子/输赢 |

> 💡 与监督学习的本质区别：**没有 (x, y) 配对**，只有"做这个动作后环境给多少分"。而且奖励常常是**延迟**的（最后一步赢了才 +1，前面哪步关键要自己归因）——这就是"时序信用分配"难题。

## 2. 回报与价值函数

### 2.1 折扣回报

从某时刻起，未来所有奖励的加权和（越远的奖励越打折）：

```
G_t = r_t + γ·r_{t+1} + γ²·r_{t+2} + ...
    = Σ γ^k · r_{t+k}
```

γ ∈ [0,1) 是折扣因子（γ 接近 1 = 看重长远）。

### 2.2 价值函数与 Q 函数

| 函数 | 定义 | 含义 |
|------|------|------|
| 状态价值 V(s) | 从状态 s 出发，按策略 π 能拿到的期望回报 | "这个局面有多好" |
| 动作价值 Q(s,a) | 在状态 s 做动作 a 后，按 π 的期望回报 | "这一步有多好" |

## 3. 贝尔曼方程：价值的自洽定义

价值函数满足一个递归的自洽方程——**贝尔曼方程**：

```
V(s) = Σ_a π(a|s) · [ R(s,a) + γ·Σ_{s'} P(s'|s,a)·V(s') ]
        ↑当前做a的即时奖励     ↑加上未来价值的折扣期望
```

一句话：**当前状态的价值 = 即时奖励 + 折扣后的未来价值**。

Q 函数的贝尔曼最优方程（Q-learning 的基础）：

```
Q*(s,a) = R(s,a) + γ · max_{a'} Q*(s', a')
```

> 💡 这就是为什么 Q-learning 能"从经验中学习"：它不断把 Q(s,a) 往 `R + γ·max Q(s',·)` 这个目标靠拢，而目标又由其他 Q 值定义——形成自举（bootstrap）。

## 4. Q-learning：学会"状态-动作"价值

### 4.1 表格版（tabular Q-learning）

维护一张 Q 表，每步更新：

```
Q(s,a) ← Q(s,a) + α · [ R + γ·max_{a'} Q(s',a') - Q(s,a) ]
                     ↑学习率        ↑TD 目标              ↑当前估计
```

括号里是"TD 误差"（目标 - 当前）。反复交互，Q 表收敛到 Q*。

### 4.2 深度版（DQN / fitted Q-learning）

状态是图像等高维时，用神经网络 Q_θ(s,a) 替代表格。Prince 第 19.4 节讲的 fitted Q-learning：

```
损失 = ( R + γ·max_{a'} Q(s',a') - Q_θ(s,a) )²
```

注意：训练目标里也含 Q 本身，所以要用**目标网络**（冻结的旧参数）算 TD 目标，避免"追着自己的尾巴跑"。

## 5. 策略梯度：直接优化策略

Q-learning 是"先学价值、再从价值导出动作"。策略梯度（policy gradient）换一条路：**直接学策略 π_θ(a|s)，用梯度上升最大化期望回报**。

核心定理（策略梯度定理）：

```
∇_θ J(θ) = E[ ∇_θ log π_θ(a|s) · R ]
```

REINFORCE 算法（最朴素的策略梯度）：采样一条轨迹，对每步用"总回报 R"做权重，增大"带来高回报的动作"的概率。减一个 baseline（如 V(s)）可降方差，就得到了 actor-critic：

```
Actor（策略网络 π_θ）: 决定做什么动作
Critic（价值网络 V_φ）: 评估当前状态好坏, 作为 baseline
```

## 6. 手算：一个 2 状态 MDP

### 6.1 设定

```
状态 A ──(动作: 右, 奖励0)──→ 状态 B ──(动作: 拿, 奖励+10)──→ 终止
状态 A ──(动作: 留, 奖励0)──→ 状态 A (原地)
```

折扣 γ = 0.9。

### 6.2 手算 Q 值

```
Q(B, 拿) = 10 + γ·0 = 10

Q(A, 右) = 0 + γ·Q(B,拿) = 0 + 0.9×10 = 9
Q(A, 留) = 0 + γ·Q(A,留) = 0 + 0.9×Q(A,留)  → 解得 Q(A,留) = 0
```

所以最优策略：在 A 选"右"（Q=9 > 0），在 B 选"拿"。**即使"右"这一步本身奖励为 0，但因为它通向高奖励的 B，价值被"传导"回来了**——这就是贝尔曼方程的精髓。

### 6.3 Q-learning 更新一步

初始 Q 表全 0，α=0.5。经历 `A →(右)→ B`：

```
Q(A,右) ← 0 + 0.5 × [ 0 + 0.9×0 - 0 ] = 0  (B 的 Q 还是 0)

经历 `B →(拿)→ 终止(奖励10)`:
Q(B,拿) ← 0 + 0.5 × [ 10 + 0 - 0 ] = 5

再经历 `A →(右)→ B`:
Q(A,右) ← 0 + 0.5 × [ 0 + 0.9×5 - 0 ] = 2.25

... 反复, Q(B,拿)→10, Q(A,右)→9
```

## 7. MATLAB：Q-learning 走格子

```matlab
% ============================================================
% Q_LEARNING_GRID.m
% 5格走廊: 智能体学从最左走到最右拿奖励
% 对应 deep-dives/16-强化学习.md
% ============================================================
clear; clc;

fprintf('=== Q-learning 走格子 ===\n\n');

%% 环境: 5 状态走廊 (1..5), 动作 1=左, 2=右
n_states = 5;
n_actions = 2;
gamma = 0.9;
alpha = 0.1;
epsilon = 0.1;   % ε-greedy 探索

% 奖励: 到达状态5给+1, 其余0
reward = @(s) (s == 5) * 1;

%% 初始化 Q 表
Q = zeros(n_states, n_actions);

%% 训练
n_episodes = 200;
for ep = 1:n_episodes
    s = 1;   % 从最左开始
    done = false;
    while ~done
        % ε-greedy 选动作
        if rand < epsilon
            a = randi(n_actions);
        else
            [~, a] = max(Q(s, :));
        end

        % 执行动作, 到新状态
        if a == 1   % 左
            s_next = max(1, s - 1);
        else        % 右
            s_next = min(n_states, s + 1);
        end
        r = reward(s_next);

        % Q-learning 更新
        Q(s, a) = Q(s, a) + alpha * (r + gamma * max(Q(s_next, :)) - Q(s, a));

        if s_next == n_states
            done = true;   % 到达终点
        end
        s = s_next;
    end
end

%% 输出 Q 表和最优策略
fprintf('学到的 Q 表:\n');
disp(round(Q, 3));

fprintf('最优策略 (每状态选 Q 最大的动作):\n');
for s = 1:n_states
    [~, best_a] = max(Q(s, :));
    a_str = {'左', '右'};
    fprintf('  状态 %d: %s (Q=%.2f)\n', s, a_str{best_a}, max(Q(s,:)));
end

fprintf('\n(除终点外, 所有状态都学出"往右走", Q 值从左到右递增)\n');
```

## 8. 从 RL 到 RLHF 到 o1/R1

这条链路把你的项目串起来了：

```
经典 RL (本章)
   → 策略梯度 PPO (deep-dives/07 RLHF 第三步)
   → RLHF: 奖励模型替代环境奖励, KL 约束保语言能力
   → o1/R1: 把"思考链"当作动作, 用 RL 训练推理能力 (GRPO 简化 PPO)
```

| 阶段 | 状态/动作 | 奖励 |
|------|-----------|------|
| 经典 RL | 环境状态 / 物理动作 | 环境给定 |
| RLHF | 对话上下文 / 生成 token | 奖励模型打分 |
| o1/R1 推理 | 思考链 / 推理步骤 | 答案正确性（可验证） |

> 💡 三者数学上用的是同一套 RL 工具（贝尔曼方程、策略梯度、PPO），只是**把"动作空间"从物理动作换成了"语言 token"或"推理步骤"**。这就是为什么吃透本章，你才能真懂 RLHF 和 o1/R1。

---

## 📌 本章要点

1. MDP：状态/动作/转移/奖励，奖励常延迟（时序信用分配）
2. 贝尔曼方程：价值 = 即时奖励 + 折扣未来价值，自举学习的关键
3. Q-learning 靠 TD 误差更新，深度版用目标网络稳定训练
4. 策略梯度直接优化策略，actor-critic 用 V(s) 降方差
5. RLHF/o1/R1 都是经典 RL 换了个"动作空间"，数学内核相同
