## 1. 核心洞察：损失 = 负对数似然

假设模型输出的是一个**概率分布** P(y|x)，那么"模型多好"可以用**似然**衡量：给定参数下，观察到真实数据的概率有多大。

```
似然 L = P(y_真实 | x, 模型参数)
```

我们想让 L 最大。但连乘容易下溢，且优化习惯"最小化"，于是取负对数：

```
损失 = -log L
```

> 💡 **这就是全部的秘密**：MSE、交叉熵……不是拍脑袋选的，而是"对某种概率分布取最大似然"的自然结果。不同的分布假设 → 不同的损失函数。

## 2. 构造损失函数的"食谱"

Prince 给出了三步配方：

```
步骤 1: 为输出 y 选择一个概率分布（取决于任务类型）
步骤 2: 写出该分布下，给定输入 x 观测到 y 的似然 P(y|x)
步骤 3: 取负对数，得到损失函数；训练时最小化它
```

| 任务 | 输出分布 | 损失函数 |
|------|----------|----------|
| 一元回归 | 高斯 N(μ, σ²) | **MSE**（均方误差） |
| 二分类 | 伯努利 Bernoulli(λ) | **二元交叉熵** |
| 多分类 | 类别分布 Categorical | **多元交叉熵** |

---

## 3. 例1：一元回归 → MSE

### 3.1 假设与推导

假设输出 y 是均值 μ = f(x,φ)、方差 σ² 的高斯分布：

```
P(y|x) = (1/√(2πσ²)) · exp(-(y-μ)² / (2σ²))
```

取负对数：

```
-log P(y|x) = (y-μ)² / (2σ²) + (1/2)·log(2πσ²)
```

忽略与 μ 无关的常数项（σ 固定），剩下：

```
损失 ∝ (y - f(x,φ))²   ← 这就是 MSE！
```

> 💡 **MSE 的隐藏假设是"误差服从高斯分布"**。如果你的回归目标有离群点（不符合高斯尾），MSE 会被离群点严重拉偏——这时该用更重尾的分布（对应 MAE 或 Huber 损失）。

### 3.2 手算

模型预测 μ=3.0，真实值 y=3.5，损失 = (3.0-3.5)² = 0.25。如果 σ²=0.5，则完整的负对数似然 = 0.25/(2×0.5) + 0.5·log(2π×0.5) = 0.25 + 0.573 = 0.823。

## 4. 例2：二分类 → 二元交叉熵

### 4.1 假设与推导

输出 y ∈ {0,1} 服从伯努利分布，P(y=1) = λ = sigmoid(f(x,φ))：

```
P(y|x) = λ^y · (1-λ)^(1-y)
```

取负对数：

```
-log P = -[ y·log(λ) + (1-y)·log(1-λ) ]
```

这就是**二元交叉熵（BCE）**。

### 4.2 手算

- 真实 y=1，模型预测 λ=0.9 → 损失 = -log(0.9) = 0.105（预测对，损失小）
- 真实 y=1，模型预测 λ=0.1 → 损失 = -log(0.1) = 2.303（预测错，损失大）
- 真实 y=0，模型预测 λ=0.9 → 损失 = -log(0.1) = 2.303（同样惩罚）

> ⚠️ 为什么分类不用 MSE？因为 sigmoid 输出 λ 是概率，MSE 的梯度 `(λ-y)·λ(1-λ)` 在 λ 接近 0 或 1 时会被 `λ(1-λ)` 压到接近 0——**梯度消失**。而 BCE 的梯度 `λ-y` 不含这项，训练高效得多。

## 5. 例3：多分类 → 多元交叉熵

### 5.1 假设与推导

K 个类别，输出服从类别分布，P(y=k) = softmax(z)_k：

```
P(y|x) = Π_k P(y=k)^{1[y=k]}
-log P = -Σ_k 1[y=k]·log(softmax(z)_k)
```

即：只对**真实类别那一项**取负对数。这就是多分类交叉熵。

### 5.2 手算

3 类，logits z = [2.0, 1.0, 0.1]，softmax：

```
softmax = [e^2, e^1, e^0.1] / (e^2+e^1+e^0.1)
        = [7.389, 2.718, 1.105] / 11.212
        = [0.659, 0.242, 0.099]
```

若真实类别是第 0 类，损失 = -log(0.659) = 0.417。

## 6. 交叉熵的深层含义

交叉熵衡量两个分布 P（真实）和 Q（预测）的差异：

```
H(P, Q) = -Σ P(i)·log Q(i)
```

当 Q = P 时最小。它是信息论里"用 Q 编码来自 P 的数据，平均需要多少比特"。

**与 KL 散度的关系**：

```
H(P, Q) = H(P) + KL(P || Q)
         ↑常数    ↑可优化项
```

最小化交叉熵 = 最小化 KL 散度 = 让 Q 逼近 P。这就是为什么 RLHF 里的 KL 约束、知识蒸馏里的软标签，底层都是同一个"拉近分布"的数学。

## 7. MATLAB：三种损失函数

```matlab
% ============================================================
% LOSS_FUNCTIONS.m
% 三种损失函数 + 最大似然统一视角
% 对应 deep-dives/11-损失函数.md
% ============================================================
clear; clc;

fprintf('=== 损失函数: 最大似然统一视角 ===\n\n');

%% 例1: MSE (一元回归, 高斯假设)
mu = 3.0; y = 3.5;
mse = (mu - y)^2;
fprintf('MSE (回归): μ=%.1f, y=%.1f → 损失 = %.2f\n', mu, y, mse);

%% 例2: 二元交叉熵 (二分类, 伯努利假设)
fprintf('\n二元交叉熵 (二分类):\n');
y_vals = [1, 1, 0];
lambda_vals = [0.9, 0.1, 0.9];
for i = 1:3
    bce = -(y_vals(i)*log(lambda_vals(i)) + (1-y_vals(i))*log(1-lambda_vals(i)));
    fprintf('  y=%d, λ=%.1f → 损失 = %.3f\n', y_vals(i), lambda_vals(i), bce);
end

%% 例3: 多元交叉熵 (多分类, 类别分布假设)
fprintf('\n多元交叉熵 (多分类):\n');
z = [2.0, 1.0, 0.1];
exp_z = exp(z - max(z));  % 数值稳定
softmax_z = exp_z / sum(exp_z);
fprintf('  logits [%.1f, %.1f, %.1f] → softmax [%.3f, %.3f, %.3f]\n', ...
    z, softmax_z);
true_class = 0;  % 第 0 类 (MATLAB 1-indexed → 1)
ce = -log(softmax_z(true_class+1));
fprintf('  真实类别=0 → 损失 = %.3f\n', ce);

%% 对比: 为什么分类不用 MSE (梯度消失演示)
fprintf('\n--- 为什么分类不用 MSE ---\n');
lambda = [0.999, 0.001];  % 极端预测
for i = 1:2
    grad_mse = (lambda(i) - 1) * lambda(i) * (1 - lambda(i));
    grad_bce = lambda(i) - 1;
    fprintf('  λ=%.3f: MSE梯度=%.6f, BCE梯度=%.3f\n', lambda(i), grad_mse, grad_bce);
end
fprintf('  → MSE 梯度被 λ(1-λ) 压到接近 0 (梯度消失), BCE 不会\n');
