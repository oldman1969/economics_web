# 正则化——对抗过拟合的系统化方法

> 模型在训练集上完美、测试集上崩盘，就是过拟合。Prince 第 9 章把对抗手段分成两类：**显式正则化**（直接改损失）和**隐式正则化**（算法/数据本身带来的约束），外加一堆实用启发式。这一章讲透"为什么 L2 有效"的数学，以及 Dropout 的真正含义。

## 1. 过拟合的根源：方差 vs 偏差

测试误差可以分解为：

```
测试误差 = 偏差² + 方差 + 噪声
```

| 项 | 含义 | 症状 |
|----|------|------|
| 偏差 | 模型族本身能力不足 | 欠拟合（训练、测试都差） |
| 方差 | 模型对训练集的随机性过度敏感 | 过拟合（训练好、测试差） |
| 噪声 | 数据本身不可约的随机性 | 无法消除 |

正则化是在**牺牲一点偏差、换取方差的大幅下降**——让模型"钝"一点，别死记硬背训练集。

## 2. 显式正则化：L2 与贝叶斯视角

### 2.1 L2（权重衰减）

在损失上加一项惩罚权重大小：

```
L_total = L_data + λ/2 · Σ φ²
        = L_data + λ/2 · ||φ||²
```

梯度变为：

```
∂L_total/∂φ = ∂L_data/∂φ + λ·φ
```

更新规则（SGD）：

```
φ ← φ - η(∂L_data/∂φ + λ·φ)
  = (1 - ηλ)·φ - η·∂L_data/∂φ
        ↑ 每次先"衰减"权重, 故名 weight decay
```

> 💡 L2 迫使权重变小 → 模型输出对输入的小扰动不那么敏感 → 函数更"平滑" → 方差下降。

### 2.2 贝叶斯视角（为什么 L2 对应高斯先验）

最大后验（MAP）估计：

```
后验 ∝ 似然 × 先验
-log后验 = -log似然 + (-log先验)
         = L_data      + (φ²/2σ₀²)   ← 若先验是高斯 N(0, σ₀²)
```

L2 惩罚 = 假设权重服从**零均值高斯先验**。λ 越大 = 先验越"确信权重接近 0"。同理，L1 惩罚（|φ|）对应**拉普拉斯先验**，且会产生稀疏权重（很多权重恰好为 0）。

## 3. 隐式正则化：SGD 和早停的魔法

### 3.1 SGD 本身就有正则化效果

小批量 SGD 的梯度含噪声，这噪声相当于在参数上加了随机扰动——研究发现 SGD 天然偏向**平坦的极小值**（flat minima），而平坦极小值泛化更好。这是"隐式"的，没有显式惩罚项。

### 3.2 早停（Early Stopping）

观察验证集：训练早期，模型学到通用规律（偏差、方差都下降）；后期开始死记硬背训练集的噪声（方差上升）。**在验证误差开始回升前停止**。

> 💡 早停的效果接近 L2 正则化，但几乎零额外成本——只需监控验证损失。

## 4. Dropout：随机丢弃的真相

训练时，每个前向以概率 p **随机关闭一批神经元**：

```
h_drop = h ⊙ m,  m_i ~ Bernoulli(1-p)
```

### 关键：测试时做什么？

测试时不丢弃，但把权重（或激活）**乘以 (1-p)** 来补偿——因为训练时每个神经元"存活"的概率只有 (1-p)，测试时全存活，输出期望会偏大 (1/(1-p)) 倍。

### 为什么有效

直观：每个神经元不能依赖"某个特定的队友"存在，必须学会**和任意子集协作**。这等价于训练了 2^n 个共享权重的子网络的集成（ensemble）。Prince 原文的经典比喻：Dropout 强迫网络**分布化**地表达知识，而非集中依赖少数关键单元。

## 5. 数据增强与标签平滑

| 方法 | 做法 | 作用 |
|------|------|------|
| 数据增强 | 对训练样本做变换（翻转/裁剪/加噪） | 扩大有效数据量，注入不变性先验 |
| 标签平滑 | 把 one-hot 标签 1 改成 1-ε，0 改成 ε/(K-1) | 防止模型对预测过度自信，抑制过拟合 |
| 迁移学习 | 用大模型预训练权重初始化 | 借用大规模数据学到的通用特征 |
| 集成 | 训练多个模型取平均 | 方差按 1/N 下降（最暴力但最有效） |

## 6. 手算：L2 梯度

设一个权重 φ=2.0，数据梯度 ∂L_data/∂φ = -0.5，λ=0.1：

```
L2 总梯度 = -0.5 + 0.1×2.0 = -0.5 + 0.2 = -0.3

无 L2 时更新: φ ← 2.0 - 0.1×(-0.5) = 2.05
有 L2 时更新: φ ← 2.0 - 0.1×(-0.3) = 2.03
```

L2 让每一步更新**略小于**纯数据梯度方向——权重被持续"往回拉"。

## 7. MATLAB：过拟合与正则化对比

```matlab
% ============================================================
% REGULARIZATION.m
% 用多项式拟合演示过拟合 vs L2 正则化
% 对应 deep-dives/12-正则化.md
% ============================================================
clear; clc;

fprintf('=== 过拟合 vs L2 正则化 ===\n\n');

%% 生成带噪声的 sin 数据
rng(0);
n_train = 10;   % 训练点很少 → 容易过拟合
x_train = linspace(0, 2*pi, n_train)';
y_train = sin(x_train) + 0.3*randn(n_train, 1);

n_test = 100;
x_test = linspace(0, 2*pi, n_test)';
y_true = sin(x_test);

%% 用高阶多项式拟合 (degree=12, 会过拟合)
degree = 12;

% --- 无正则化 ---
X_train_poly = poly_features(x_train, degree);
X_test_poly  = poly_features(x_test, degree);

w_no_reg = (X_train_poly' * X_train_poly) \ (X_train_poly' * y_train);  % 最小二乘

% --- L2 正则化 (岭回归) ---
lambda = 0.5;
A = X_train_poly' * X_train_poly + lambda * eye(degree+1);
w_l2 = A \ (X_train_poly' * y_train);

%% 计算误差
y_pred_no_reg = X_test_poly * w_no_reg;
y_pred_l2     = X_test_poly * w_l2;

mse_no_reg = mean((y_pred_no_reg - y_true).^2);
mse_l2     = mean((y_pred_l2 - y_true).^2);

fprintf('测试 MSE: 无正则化 = %.4f, L2(λ=%.1f) = %.4f\n', mse_no_reg, lambda, mse_l2);
fprintf('(无正则化在训练集上几乎完美, 但测试集 MSE 更大 → 过拟合)\n');

%% 可视化
figure('Position', [100 100 900 400]);
plot(x_test, y_true, 'k-', 'LineWidth', 1.5); hold on;
plot(x_train, y_train, 'ro', 'MarkerSize', 8, 'MarkerFaceColor', 'r');
plot(x_test, y_pred_no_reg, 'b--', 'LineWidth', 1.5);
plot(x_test, y_pred_l2, 'g-', 'LineWidth', 2);
legend('真实函数', '训练点', '无正则化(过拟合)', 'L2正则化', 'Location', 'best');
title('L2 正则化抑制过拟合');
xlabel('x'); ylabel('y'); grid on;

%% 辅助函数
function Xp = poly_features(x, degree)
    Xp = zeros(length(x), degree+1);
    for d = 0:degree
        Xp(:, d+1) = x.^d;
    end
end
```

运行后：无正则化的曲线剧烈摆动、穿过每个训练点（过拟合），L2 的曲线平滑贴近真实 sin 函数，测试 MSE 显著更低。

## 📌 本章要点

1. 正则化 = 牺牲偏差换方差下降，本质是"让模型钝一点"
2. L2 权重衰减对应"高斯先验"，L1 对应"拉普拉斯先验"（稀疏）
3. SGD 噪声 + 早停是"免费"的隐式正则化
4. Dropout 测试时乘 (1-p) 补偿，等价于训练共享权重的子网络集成
5. 数据增强、标签平滑、迁移学习、集成——都是工程上最常用的抗过拟合手段
