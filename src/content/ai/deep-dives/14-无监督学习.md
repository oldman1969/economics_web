## 1. 无监督学习的三大类别

Prince 给出的分类法：

```
无监督学习
├── 1. 降维 (dimensionality reduction)
│       PCA、t-SNE、自编码器 → 找数据的低维表示
│
├── 2. 聚类 (clustering)
│       K-means → 把数据分成组
│
└── 3. 生成模型 (generative models)
        GAN、VAE、归一化流、扩散模型 → 学习 P(x) 本身
```

> 💡 关键区别：降维和聚类是**判别**任务（找表示/分组），生成模型是**生成**任务（学习数据分布 P(x)，从而能采样新样本）。后者是当下 AIGC（文生图、文生视频）的理论根基。

---

## 2. 生成模型：统一的目标

生成模型的目标是学习数据的概率分布 P(x)。什么是"好的生成模型"？Prince 给了三个标准：

1. **采样质量**：生成的样本逼真、多样（FID 等指标衡量）
2. **似然**：能给新样本 x 分配高的概率（好模型认为真实数据"不意外"）
3. **潜表示**：学到的隐变量 z 有意义、可操控（比如 z 的某维度对应"笑容程度"）

**四种方法殊途同归**，都是想办法逼近 P(x)，区别在"怎么逼近"：

| 方法 | 核心思想 | 隐变量 | 采样方式 |
|------|----------|--------|----------|
| GAN | 对抗：生成器 vs 判别器 | 有 | 从噪声 z 直接生成 |
| VAE | 变分推断下界 | 有（连续） | 从学到的 z 分布采样 |
| 归一化流 | 可逆变换 + 变量替换 | 有 | 从 z 推 x（可逆） |
| 扩散模型 | 加噪→去噪 | 无（隐式） | 从噪声逐步去噪 |

## 3. 隐变量与自编码器

### 3.1 隐变量 z

生成模型的共同假设：数据 x 背后有个低维的**隐变量 z**（"本质因素"），生成过程是 z → x。比如人脸照片 x，隐变量 z 是"身份、表情、角度、光照"。

```
z (低维本质) --生成器--> x (高维观测)
```

学习 P(x) 就是学习"z 的分布"和"z 到 x 的映射"。

### 3.2 自编码器（AE）

最朴素的隐变量模型：

```
编码器: z = enc(x)    (x → z, 降维)
解码器: x̂ = dec(z)    (z → x, 重建)
损失:   ||x - x̂||²   (重建误差)
```

问题：普通 AE 的 z 空间**不连续**——两个 z 之间的点解码出来可能是乱码。VAE（Ch.17）通过强制 z 服从高斯分布解决了这个，使 z 空间可采样。

## 4. 四类生成模型：一张地图

```
                   学习 P(x) 的四条路
                          │
        ┌─────────┬───────┼────────┬──────────┐
        │         │       │        │          │
      GAN       VAE    归一化流   扩散模型
     (对抗)   (变分)   (可逆)    (去噪)
    Ch.15    Ch.17    Ch.16     Ch.18
        │         │       │        │
   生成最锐利  潜空间好  似然精确  生成最稳定
   但训练难   但样本模糊  但架构受限  但采样慢
```

| 维度 | GAN | VAE | 归一化流 | 扩散 |
|------|-----|-----|----------|------|
| 训练难度 | 高（模式崩塌） | 中 | 低（但架构受限） | 中（但慢） |
| 采样质量 | 高 | 中（模糊） | 中 | **最高** |
| 似然可算 | 否 | 下界 | **精确** | 下界/近似 |
| 代表性应用 | 早期图像生成 | 生成+压缩 | 密度估计 | **DALL·E/Sora** |

> 💡 2022 年后的王者是**扩散模型**——采样质量最高，Sora/DALL·E/Midjourney 全是它。这就是下一章（deep-dives/15）要深挖的。

## 5. 手算：PCA 与最大似然

PCA（主成分分析）可以看作**高斯隐变量模型**的特例（这是 Prince 书里一个深刻的联系）。

### 5.1 PCA 的思想

找数据方差最大的方向，把数据投影到低维。二维数据：

```
数据点: (1,1), (2,2), (3,3), (4,4)  ← 都在 y=x 这条线上
协方差矩阵: C = [[1.67, 1.67], [1.67, 1.67]]
特征值: λ₁ = 3.33, λ₂ = 0
主成分: v₁ = [0.707, 0.707]  ← y=x 方向
```

投影到 v₁ 上，4 个点变成 1 维坐标，信息零损失（因为 λ₂=0）。

### 5.2 与最大似然的联系

在高斯隐变量模型中，若噪声为 0，用最大似然估计隐变量 z 和线性映射，**等价于 PCA**。PCA 不是"降维工具"这么简单——它假设数据来自一个**高斯 + 线性生成过程**。

## 6. MATLAB：PCA 降维

```matlab
% ============================================================
% PCA_DEMO.m
% PCA 降维演示 + 与最大似然(高斯隐变量)的联系
% 对应 deep-dives/14-无监督学习.md
% ============================================================
clear; clc;

fprintf('=== PCA 降维演示 ===\n\n');

%% 生成 2D 数据 (强相关 → 适合降维)
rng(42);
n = 100;
t = randn(n, 1);                    % 隐变量
X = [t + 0.2*randn(n,1), 2*t + 0.2*randn(n,1)];  % x1 ≈ t, x2 ≈ 2t

%% PCA
X_center = X - mean(X);
C = (X_center' * X_center) / (n - 1);   % 协方差矩阵
[V, D] = eig(C);                         % 特征值分解
[~, idx] = sort(diag(D), 'descend');
V = V(:, idx);                           % 主成分 (按方差降序)

% 投影到第一主成分
z = X_center * V(:, 1);

fprintf('协方差矩阵:\n'); disp(round(C, 3));
fprintf('\n特征值 (方差): [%.2f, %.2f]\n', D(idx(1),idx(1)), D(idx(2),idx(2)));
fprintf('第一主成分: [%.3f, %.3f]\n', V(1,1), V(2,1));
fprintf('(≈ [0.45, 0.89], 即 x2≈2·x1 方向)\n');
fprintf('\n投影到 1 维后保留方差比例: %.1f%%\n', ...
    100 * D(idx(1),idx(1)) / trace(D));

%% 重建 (用 1 维重建 2 维)
X_recon = z * V(:, 1)' + mean(X);
recon_error = mean(sum((X - X_recon).^2, 2));
fprintf('1 维重建误差: %.4f\n', recon_error);

%% 可视化
figure('Position', [100 100 900 400]);
subplot(1,2,1);
scatter(X(:,1), X(:,2), 10, 'b', 'filled'); hold on;
quiver(mean(X(:,1)), mean(X(:,2)), V(1,1), V(2,1), 3, 'r', 'LineWidth', 2);
title('原始数据 + 第一主成分'); xlabel('x1'); ylabel('x2'); grid on;

subplot(1,2,2);
histogram(z, 30); title('投影到 1 维后的分布 (隐变量 z)'); xlabel('z');
grid on;
```

## 📌 本章要点

1. 无监督 = 降维 / 聚类 / 生成模型三类，前两者判别、后者生成

4. PCA 是高斯隐变量模型的特例——降维和生成模型有深层联系
