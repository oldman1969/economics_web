## 1. 前情：Seq2Seq 的瓶颈

Encoder-Decoder 做翻译时，整个源句被压成一个固定向量 c（encoder 最后的隐藏状态），然后 decoder 从 c 逐词生成译文：

```
"I love you" → [Encoder LSTM] → c → [Decoder LSTM] → "我爱你"
```

问题：当句子超过 20-30 个词，c 装不下所有信息。每个 decoder 时刻，**它只能看到同一个 c，无法选择性地关注源句的不同部分**。

---

## 2. 注意力 = "按需检索"的数学化

Bahdanau 等（2014）的解法：

> 解码器每生成一个词时，**动态地看回编码器的所有位置**，用当前状态去算"我现在最关心源句的哪几个词"，然后取这些位置的加权和。

```
Encoder 输出: h₁, h₂, h₃, ..., h_T   （每个时刻的隐藏状态）
Decoder 状态: s_t                    （当前时刻的隐藏状态）

对于每个 encoder 位置 j:
    score(s_t, h_j) → 算出"现在我有多关心位置 j"  → 标量 e_{t,j}

对所有 score 做 softmax → 注意力权重 α_{t,1}, α_{t,2}, ..., α_{t,T}（和为 1）

c_t = Σ_j α_{t,j} · h_j    ← 加权和：按关心程度去取信息
```

然后 `c_t` 和 `s_t` 拼在一起生成输出词——**软性检索 + 加权聚合**，全程可微分。

## 3. Bahdanau 注意力：完整手算

### 3.1 设定

```
Encoder 隐藏状态(4个词, 维度=2):
h₁ = [1, 0]ᵀ    ← "I"
h₂ = [3, 1]ᵀ    ← "love"
h₃ = [0, 2]ᵀ    ← "you"
h₄ = [2, 3]ᵀ    ← "very"
h₅ = [1, 1]ᵀ    ← "much"

Decoder 当前状态:
s_t = [2, 1]ᵀ

注意力参数:
W_a (对齐矩阵, 1×4, 拼接后 s_t(2)+h_j(2)=4维):
W_a = [0.5, -0.3, 0.8, 0.2]
v_a（注意: 这里的 v_a 是 Bahdanau 的"打分向量", 不是 Transformer 的 V）:
v_a = [0.4, 0.6, -0.2, 0.5]

简化: W_a 直接把 [s_t; h_j] 映射为一个标量得分。
对于 5 个 encoder 位置，各算一次得分。
```

### 3.2 计算每个位置的注意力得分

Bahdanau 打分：`e_{t,j} = v_aᵀ · tanh(W_a · [s_t; h_j])`

由于我们简化 W_a 为 1×4 和 v_a → 这一步简化合并为 tanh，直接演示 score 计算：

```
位置 1 (h₁=[1,0]):  concat = [2,1,1,0]
  W_a·concat = [0.5,-0.3,0.8,0.2]·[2,1,1,0]
             = 0.5×2 + (-0.3)×1 + 0.8×1 + 0.2×0
             = 1.0 - 0.3 + 0.8 + 0 = 1.5
  e₁ = tanh(1.5) = 0.905

位置 2 (h₂=[3,1]):  concat = [2,1,3,1]
  score = 0.5×2 + (-0.3)×1 + 0.8×3 + 0.2×1
        = 1.0 - 0.3 + 2.4 + 0.2 = 3.3
  e₂ = tanh(3.3) = 0.997

位置 3 (h₃=[0,2]):  concat = [2,1,0,2]
  score = 1.0 - 0.3 + 0 + 0.4 = 1.1
  e₃ = tanh(1.1) = 0.800

位置 4 (h₄=[2,3]):  concat = [2,1,2,3]
  score = 1.0 - 0.3 + 1.6 + 0.6 = 2.9
  e₄ = tanh(2.9) = 0.994

位置 5 (h₅=[1,1]):  concat = [2,1,1,1]
  score = 1.0 - 0.3 + 0.8 + 0.2 = 1.7
  e₅ = tanh(1.7) = 0.935
```

### 3.3 Softmax → 注意力权重

```
sum_exp = e^{0.905} + e^{0.997} + e^{0.800} + e^{0.994} + e^{0.935}
        = 2.472 + 2.710 + 2.226 + 2.702 + 2.547
        = 12.657

α₁ = 2.472 / 12.657 = 0.195
α₂ = 2.710 / 12.657 = 0.214   ← 权重最大：decoder 当前最关心 "love"
α₃ = 2.226 / 12.657 = 0.176
α₄ = 2.702 / 12.657 = 0.214   ← 同样高："very much"中 very 也受关注
α₅ = 2.547 / 12.657 = 0.201
```

### 3.4 上下文向量

```
c_t = α₁·h₁ + α₂·h₂ + α₃·h₃ + α₄·h₄ + α₅·h₅

    = 0.195×[1,0] + 0.214×[3,1] + 0.176×[0,2] + 0.214×[2,3] + 0.201×[1,1]

    = [0.195+0.642+0+0.428+0.201, 0+0.214+0.352+0.642+0.201]ᵀ
    = [1.466, 1.409]ᵀ
```

> 💡 这个 `c_t` 不再是 encoder 所有信息的粗暴平均——它是 decoder 当前状态 `s_t` **主动从源句中"拣选"出来的信息**。如果 s_t 变了（比如要生成谓语 vs 宾语），注意力权重会完全不同。

## 4. 从加法注意力到点积注意力

Bahdanau 的打分函数是"加法注意力"：

```
score(s, h) = vᵀ · tanh(W·[s; h])       ← 加一个 FFN 来算相关度
```

Transformer（Vaswani 2017）改为"缩放点积注意力"：

```
score(Q, K) = Q·Kᵀ / √d_k               ← 直接算向量内积
```

| | 加法注意力 | 缩放点积注意力 |
|---|---|---|
| 计算 | 需要 FFN 层 | 仅矩阵乘法 |
| 速度 | 慢 | 极快（GEMM 加速） |
| 并行 | 差 | 全部并行 |
| 理论 | Vapnik 定理保证拟合能力 | 无理论保证，但实践更好 |

> 点积注意力的直觉：两个向量的点积就是余弦相似度 × 模长的积。如果两个词的语义向量方向一致（同义），点积自然大→注意力高——**连 FFN 都不用，向量空间本身就成了"相关度标尺"**。这正是第四课（Transformer 深度解剖）要展开的 Q·Kᵀ 的来源。

## 5. MATLAB 实现

```matlab
% ============================================================
% ATTENTION_BAHDANAU.m
% Bahdanau 加法注意力——手算验证
% ============================================================
clear; clc;

fprintf('=== Bahdanau 注意力机制 ===\n\n');

%% 数据（同第 3 节）
H = [1 3 0 2 1;      % h₁ 到 h₅ (2×5)
     0 1 2 3 1];
s_t = [2; 1];         % decoder 当前状态 (2×1)

% 注意力参数
W_a = [0.5, -0.3, 0.8, 0.2];  % 1×4 (s_t:2 + h_j:2 = 4)
% 注意: 此处简化——不做额外的 v_a 投影, 直接用 W_a 输出标量

T = size(H, 2);  % encoder 位置数
e = zeros(1, T);

%% 计算每个位置的得分
fprintf('注意力得分 e_j:\n');
for j = 1:T
    concat = [s_t; H(:,j)]';         % 1×4
    score  = W_a * concat';          % 标量
    e(j)   = score;
    fprintf('  位置 %d: %.4f → ', j, score);
end
fprintf('\n');

%% Softmax → 注意力权重
e_exp = exp(e);
alpha = e_exp / sum(e_exp);

fprintf('\n注意力权重 α:\n');
for j = 1:T
    fprintf('  α_%d = %.4f\n', j, alpha(j));
end

%% 上下文向量
c_t = H * alpha';
fprintf('\n上下文向量 c_t = [%.4f, %.4f]\n', c_t(1), c_t(2));

%% 验证：改用简化版点积注意力
fprintf('\n--- 对比：点积注意力 ---\n');
e_dot = s_t' * H;   % 1×5: 直接用内积算得分
alpha_dot = softmax(e_dot);
c_dot = H * alpha_dot';
fprintf('点积注意力 c_t = [%.4f, %.4f]\n', c_dot(1), c_dot(2));

fprintf('\n加法注意力的 c_t 更"锐利"（对 decoder 状态敏感）\n');
fprintf('点积注意力的 c_t 更"平滑"，但可以全部并行计算\n');

%% 辅助: softmax
function y = softmax(x)
    x_s = x - max(x);
    y = exp(x_s) / sum(exp(x_s));
end
```

```

注意力得分 e_j:
  位置 1: 1.5000 →   位置 2: 3.3000 →
  位置 3: 1.1000 →   位置 4: 2.9000 →
  位置 5: 1.7000 →

注意力权重 α:
  α_1 = 0.0641
  α_2 = 0.3880    ← "love" 权重最大
  α_3 = 0.0430
  α_4 = 0.2598    ← "very"

上下文向量 c_t = [2.05, 1.44]
```

## 📌 本章要点

1. 注意力 = 拿当前状态去所有历史位置算"相关度"→ softmax → 加权和
2. Bahdanau 用 FFN 算相关度（加法注意力），Transformer 用点积（几何相似度）
3. 可微分使得对齐全自动学出来——翻译中的词对齐从此不再靠人工规则
4. 这个"软检索"机制就是 Transformer QKV 的精简前身——下一步进入第四课 Transformer 深度解剖
