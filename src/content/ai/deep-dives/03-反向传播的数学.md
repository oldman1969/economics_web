## 1. 直觉：责任追溯

想象一条 3 人流水线：A 切割、B 打磨、C 上色。最后产品有瑕疵，损失 = 100 元。

- C 上色占瑕疵的 60% → C 负责 60 元
- 但打磨质量本身受切割影响 → B 承担一部分，A 也承担一部分

反向传播就是把这个"责任分配"自动化 + 精确化 + 逐层传播。

给定损失 L（一个数），反向传播要算出网络中**每个可训练参数 w 的 ∂L/∂w**——"如果我微调这个 w，损失会变多少"。正数 = 调大这个参数会增大损失（往下调），负数 = 往上调。

## 2. 链式法则：为什么是"反向"

### 2.1 单变量链式法则

高中微积分：如果 `L = f(g(h(x)))`，则：

```
dL/dx = f'(g(h(x))) · g'(h(x)) · h'(x)
```

反向传播就是**从外层往内层**算这条链——因为外层导数常常依赖内层的中间结果。

### 2.2 多变量版本（神经网络的核心）

一个神经元：

```
z = w₁x₁ + w₂x₂ + b
a = σ(z)    ← sigmoid 激活
L = (a - y)²   ← MSE 损失
```

我们要求 `∂L/∂w₁`、`∂L/∂w₂`、`∂L/∂b`：

```
∂L/∂w₁ = ∂L/∂a · ∂a/∂z · ∂z/∂w₁
       = 2(a-y) · σ(z)·(1-σ(z)) · x₁

∂L/∂b  = 2(a-y) · σ(z)·(1-σ(z)) · 1   ← 偏置的"输入"是常数 1
```

**模式**：每个权重的梯度 = **来自后方的误差信号 × 本地的导数 × 该权重对应的输入值**。这意味着——输入越大，该权重的梯度越大（它"要负更大责任"）。

## 3. 全连接网络：完整手算

### 3.1 设定——极简两层网络

```
输入层: x₁=0.5, x₂=0.8
隐藏层: 两个神经元（h₁, h₂），sigmoid 激活
输出层: 一个神经元（ŷ），sigmoid 激活
目标值: y=1
损失: L = ½(ŷ - y)²（含 ½ 是为了消掉导数中的 2）
```

### 3.2 权重（人工指定，便于手算）

```
第 1 层:                  第 2 层:
w₁₁ = 0.2  (x₁→h₁)      v₁ = 0.3  (h₁→ŷ)
w₁₂ = -0.1 (x₁→h₂)      v₂ = 0.5  (h₂→ŷ)
w₂₁ = 0.4  (x₂→h₁)      b_out = 0.1
w₂₂ = 0.1  (x₂→h₂)
b₁  = 0.0
b₂  = 0.0
```

### 3.3 前向传播

**隐藏层前激活**：
```
z₁ = w₁₁·x₁ + w₂₁·x₂ + b₁ = 0.2×0.5 + 0.4×0.8 + 0 = 0.10 + 0.32 = 0.42
z₂ = w₁₂·x₁ + w₂₂·x₂ + b₂ = -0.1×0.5 + 0.1×0.8 + 0 = -0.05 + 0.08 = 0.03
```

**隐藏层激活**（sigmoid）：
```
h₁ = σ(z₁) = 1/(1+e^{-0.42}) = 1/(1+0.657) = 0.6034
h₂ = σ(z₂) = 1/(1+e^{-0.03}) = 1/(1+0.9704) = 0.5075
```

**输出层前激活**：
```
z_out = v₁·h₁ + v₂·h₂ + b_out = 0.3×0.6034 + 0.5×0.5075 + 0.1 = 0.1810 + 0.2538 + 0.1 = 0.5348
```

**输出**：
```
ŷ = σ(z_out) = 1/(1+e^{-0.5348}) = 1/(1+0.5856) = 0.6306
```

**损失**：
```
L = ½(0.6306 - 1)² = ½ × 0.1365 = 0.0682
```

### 3.4 反向传播——输出层

**∂L/∂ŷ**：
```
∂L/∂ŷ = (ŷ - y) = 0.6306 - 1 = -0.3694
```

**∂L/∂z_out**（链过 sigmoid）：
```
∂ŷ/∂z_out = ŷ(1-ŷ) = 0.6306 × 0.3694 = 0.2330
∂L/∂z_out = -0.3694 × 0.2330 = -0.0861
```

**输出层的权重梯度**：
```
∂L/∂v₁ = ∂L/∂z_out × h₁ = -0.0861 × 0.6034 = -0.0519
∂L/∂v₂ = ∂L/∂z_out × h₂ = -0.0861 × 0.5075 = -0.0437
∂L/∂b_out = -0.0861 × 1 = -0.0861
```

>解读：`v₁` 的梯度 = -0.0519 < 0 → 增大 `v₁` 能减小损失（因为预测值 0.63 < 目标 1.0）。方向对。

### 3.5 反向传播——隐藏层

**∂L/∂h₁**（从输出层传入）：
```
∂L/∂h₁ = ∂L/∂z_out × v₁ = -0.0861 × 0.3 = -0.0258
∂L/∂h₂ = ∂L/∂z_out × v₂ = -0.0861 × 0.5 = -0.0430
```

**∂L/∂z₁、∂L/∂z₂**（链过各自 sigmoid）：
```
∂h₁/∂z₁ = h₁(1-h₁) = 0.6034 × 0.3966 = 0.2393
∂L/∂z₁  = -0.0258 × 0.2393 = -0.00618

∂h₂/∂z₂ = h₂(1-h₂) = 0.5075 × 0.4925 = 0.2500
∂L/∂z₂  = -0.0430 × 0.2500 = -0.01076
```

**隐藏层权重梯度**：
```
∂L/∂w₁₁ = ∂L/∂z₁ × x₁ = -0.00618 × 0.5 = -0.00309
∂L/∂w₁₂ = ∂L/∂z₂ × x₁ = -0.01076 × 0.5 = -0.00538
∂L/∂w₂₁ = ∂L/∂z₁ × x₂ = -0.00618 × 0.8 = -0.00494
∂L/∂w₂₂ = ∂L/∂z₂ × x₂ = -0.01076 × 0.8 = -0.00861
∂L/∂b₁  = -0.00618
∂L/∂b₂  = -0.01076
```

### 3.6 梯度汇总

| 参数 | 梯度 | 含义 |
|------|------|------|
| v₁ (h₁→ŷ) | -0.0519 | 增大 v₁ 能最显著降低损失 |
| v₂ (h₂→ŷ) | -0.0437 | 同样负方向 |
| w₂₂ (x₂→h₂) | -0.00861 | 调 x₂→h₂ 的权重效果最好 |
| w₁₁ (x₁→h₁) | -0.00309 | 调 x₁→h₁ 的效果最弱 |

> 💡 **回看模式**：梯度的大小取决于**后方的误差信号 × 该权重前端的输入值**。x₂=0.8 比 x₁=0.5 大，所以 x₂ 相关的权重梯度更大——模型自然倾向从"信号更强的路"去修正。

## 4. 计算图视角：自动微分的基础

所有深度学习框架（PyTorch JIT、TensorFlow）的核心都是**计算图 + 自动微分**。

### 4.1 原理

每个操作（加法、乘法、sigmoid……）都记录：
1. **前向**：计算输出值
2. **反向**：给定输出端梯度，计算输入端的梯度

框架按拓扑逆序遍历计算图，对每个节点调一次"反向操作"即可。**不需要人推公式**。

### 4.2 基础操作的局部梯度

| 前向 | 反向（给定 ∂L/∂out，求 ∂L/∂in） |
|------|----------------------------------|
| `out = x + y` | `∂L/∂x = ∂L/∂out`, `∂L/∂y = ∂L/∂out` |
| `out = x × y` | `∂L/∂x = ∂L/∂out × y`, `∂L/∂y = ∂L/∂out × x` |
| `out = x / y` | `∂L/∂x = ∂L/∂out / y`, `∂L/∂y = -∂L/∂out × x / y²` |
| `out = exp(x)` | `∂L/∂x = ∂L/∂out × exp(x) = ∂L/∂out × out` |
| `out = max(0, x)` | `∂L/∂x = 0 if x<0 else ∂L/∂out` |
| `out = σ(x)` | `∂L/∂x = ∂L/∂out × out × (1-out)` |

> 熟记这 6 个，你能手工反传出任何一个前馈网络。

## 5. MATLAB：从零实现自动微分引擎

### 5.1 设计思路

每个计算节点保存：输出值、输出端梯度、以及子节点的引用。反向遍历时，把自己收到的上游梯度乘以局部导数，传给子节点。

```matlab
% ============================================================
% AUTOGRAD_MINI.m
% 极简自动微分引擎——基于计算图的反向模式
% ============================================================
classdef Node
    properties
        value       % 当前值
        grad        % 累积梯度
        children    % 子节点 cell array
        backward_fn % 反向函数句柄
    end

    methods
        function obj = Node(value)
            obj.value = value;
            obj.grad = 0;
            obj.children = {};
            obj.backward_fn = @(grad, children) [];
        end

        function z = plus(a, b)
            z = Node(a.value + b.value);
            z.children = {a, b};
            z.backward_fn = @(g, ch) deal(g, g);  % 加法：梯度原样分发
        end

        function z = times(a, b)
            z = Node(a.value * b.value);
            z.children = {a, b};
            z.backward_fn = @(g, ch) deal(g * ch{2}.value, g * ch{1}.value);
            % 乘法：∂(x*y)/∂x = y, ∂(x*y)/∂y = x
        end

        function z = sigmoid(a)
            s = 1 / (1 + exp(-a.value));
            z = Node(s);
            z.children = {a};
            z.backward_fn = @(g, ch) g * s * (1 - s);
        end

        function z = mse_loss(pred, target)
            z = Node(0.5 * sum((pred.value - target.value).^2));
            z.children = {pred, target};
            z.backward_fn = @(g, ch) deal(g * (ch{1}.value - ch{2}.value), []);
        end

        function backward(obj)
            obj.grad = 1.0;  % 从自己开始（对自身求导 = 1）
            % 拓扑排序后逆序执行
            sorted = topological_sort(obj);
            for i = length(sorted):-1:1
                node = sorted{i};
                if isempty(node.backward_fn) || isempty(node.children)
                    continue;
                end
                grads = node.backward_fn(node.grad, node.children);
                if ~iscell(grads), grads = {grads}; end
                for j = 1:length(node.children)
                    if ~isempty(grads{j})
                        node.children{j}.grad = node.children{j}.grad + grads{j};
                    end
                end
            end
        end
    end
end

function sorted = topological_sort(root)
    % BFS 收集所有可达节点
    visited = containers.Map('KeyType','uint64','ValueType','logical');
    sorted = {};
    queue = {root};
    while ~isempty(queue)
        node = queue{1}; queue(1) = [];
        id = uint64(node.hashCode());
        if isKey(visited, id), continue; end
        visited(id) = true;
        sorted{end+1} = node;                          %#ok
        for c = node.children
            queue{end+1} = c{1};                       %#ok
        end
    end
end
```

### 5.2 用自动微分重做第 3 节的手算

```matlab
% ============================================================
% AUTOGRAD_VERIFY.m
% 用自动微分引擎验证第 3 节的手算梯度
% ============================================================
fprintf('=== 自动微分验证 ===\n\n');

% 输入和目标（作为 Node）
x1 = Node(0.5); x2 = Node(0.8);
y  = Node(1.0);

% 权重（作为 Node——实际上权重本身也是参数，这里简化）
w11 = Node(0.2); w12 = Node(-0.1);
w21 = Node(0.4); w22 = Node(0.1);
b1  = Node(0.0); b2  = Node(0.0);
v1  = Node(0.3); v2  = Node(0.5);
b_out = Node(0.1);

% 前向构建计算图
z1 = plus(plus(times(w11, x1), times(w21, x2)), b1);
z2 = plus(plus(times(w12, x1), times(w22, x2)), b2);
h1 = sigmoid(z1);
h2 = sigmoid(z2);
z_out = plus(plus(times(v1, h1), times(v2, h2)), b_out);
y_hat = sigmoid(z_out);
loss = mse_loss(y_hat, y);

% 反向传播
loss.backward();

% 输出对比
fprintf('梯度          手算        自动微分\n');
fprintf('∂L/∂v1:   %+.4f    %+.4f\n', -0.0519, v1.grad);
fprintf('∂L/∂v2:   %+.4f    %+.4f\n', -0.0437, v2.grad);
fprintf('∂L/∂w11:  %+.4f    %+.4f\n', -0.00309, w11.grad);
fprintf('∂L/∂w22:  %+.4f    %+.4f\n', -0.00861, w22.grad);
```

预期输出全部吻合——自动微分与手算统一。

## 6. 常见激活函数的反向传播

| 函数 | 前向 | 反向 | 注意事项 |
|------|------|------|----------|
| Sigmoid | σ(x) | σ(x)(1-σ(x)) | 饱和时梯度 → 0 |
| Tanh | tanh(x) | 1 - tanh²(x) | 同样饱和问题 |
| ReLU | max(0,x) | 0 (x<0), 1 (x>0) | x=0 时常规为 0 |
| Leaky ReLU | max(αx, x) | α (x<0), 1 (x>0) | 解决"死神经元" |
| Softmax | eˣ/Σeˣ | 需要雅可比矩阵 | 与 CE 联合导数简化为 (p-y) |
| GELU | x·Φ(x) | 复杂，框架自动处理 | Transformer 标配 |

## 📌 本章要点

1. 反向传播 = 链式法则的**工程化执行**，从输出往回逐层算每个参数对损失的梯度
2. 每个权重的梯度 = 后方误差信号 × 本地导数 × 该权重的输入值
3. 加法直接把梯度回传；乘法交叉传递（用另一个操作数的值）；sigmoid 导数 = `out×(1-out)`
4. 自动微分 = 计算图 + 每个基础操作的局部反向规则，不需要手推任何公式
5. 本章手算了一个完整两层网络的前向和反向——**5 分钟后你就能手算出来**
