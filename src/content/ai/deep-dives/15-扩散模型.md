## 1. 核心思想：加噪与去噪的对偶

扩散模型的直觉来自热力学里的扩散：墨水在清水里扩散，最终均匀。反过来，如果知道扩散规律，理论上能从"均匀状态"倒推回最初的墨滴。

```
真实图像 x₀ (清晰)
   ↓ 加噪 (正向, 固定, 无需学习)
x₁, x₂, ..., x_T → x_T ≈ 纯高斯噪声
   ↓ 去噪 (逆向, 用神经网络学习)
x₀ 重建

生成时: 采样一个纯噪声 x_T ~ N(0,I), 走逆向去噪 → 新图像 x₀
```

> 💡 前向是**固定的**（按时间表加噪，无需学习）；逆向是**要学的**（每一步"怎么去掉一点噪声"由一个神经网络近似）。

---

## 2. 前向过程：把图像变成噪声

### 2.1 单步加噪

每一时间步，图像稍微加一点高斯噪声：

```
x_t = √(1-β_t) · x_{t-1} + √β_t · ε_t,   ε_t ~ N(0, I)
```

β_t 是噪声调度（noise schedule），从 β₁ 很小（几乎不加噪）到 β_T 较大。

### 2.2 闭式直达任意步（关键技巧）

因为高斯噪声相加仍是高斯，可以**跳过中间步，直接算 x_t**：

```
x_t = √(ᾱ_t) · x₀ + √(1-ᾱ_t) · ε,   ε ~ N(0, I)
     其中 ᾱ_t = Π_{s=1}^t (1-β_s)   ← 累乘
```

ᾱ_t 随 t 单调递减到接近 0。当 ᾱ_t → 0 时，x_t → 纯噪声。

> 💡 这个"闭式"是扩散模型训练能高效的关键：训练时不必真的走 T 步前向，直接一步跳到 x_t 即可。

---

## 3. 逆向过程：把噪声变回图像

逆向是逐步去噪。Prince 书里强调：**当 β_t 很小时，逆向过程也可以用高斯近似**：

```
x_{t-1} ~ N( μ_θ(x_t, t), σ_t² I )
```

均值和方差由一个神经网络预测（实际中方差常固定，只学均值）。整个逆向链：

```
p(x₀) = ∫ p(x_T) Π p_θ(x_{t-1} | x_t) dx_{1..T}
```

从 p(x_T)=N(0,I) 出发，一步步采样 x_{T-1}, ..., x₀，得到生成图像。

---

## 4. 训练：只学一件事——预测噪声

**核心训练目标（DDPM, Ho et al. 2020）**：

```
L = E[ || ε - ε_θ(x_t, t) ||² ]
```

含义：给神经网络一个"被加了 ε 噪声的图 x_t"和"时间步 t"，让它**预测当时加进去的噪声 ε**。预测准了，就能从 x_t 恢复 x_{t-1}。

这个目标极其简单：**就是一个 MSE 回归**——输入含噪图，输出噪声。

---

## 5. 损失重参数化：为什么这么简洁

Prince 第 18.5 节讲了关键的一步。原本的损失（变分下界）很复杂，但经过重参数化后，可以写成：

```
L = E_{t, x₀, ε}[ || ε - ε_θ(√ᾱ_t·x₀ + √(1-ᾱ_t)·ε, t) ||² ]
```

- x₀ 从真实数据采样
- t 从 {1..T} 均匀采样
- ε 从 N(0,I) 采样
- 构造 x_t = √ᾱ_t·x₀ + √(1-ᾱ_t)·ε（用闭式）
- 让网络预测 ε

**整个训练循环就这三行**。这是扩散模型优雅的极致：复杂的生成模型，训练起来却和普通回归一样简单。

## 6. 手算：一个 1 维像素的扩散

设图像只有 1 个像素（1 维），x₀ = 2.0。噪声调度简化为 β=0.1（每步）。

### 6.1 前向 3 步

```
x₁ = √0.9 · x₀ + √0.1 · ε₁
   = 0.949 × 2.0 + 0.316 × ε₁
   = 1.897 + 0.316·ε₁

若 ε₁ = 0.5:
x₁ = 1.897 + 0.158 = 2.055

x₂ = √0.9 · x₁ + √0.1 · ε₂
   = 0.949 × 2.055 + 0.316·ε₂
   (继续加噪, 值在 0 附近随机游走, 最终趋向 N(0, 1/(1-β)) )
```

### 6.2 闭式直达 x₃

ᾱ₃ = (1-0.1)³ = 0.9³ = 0.729：

```
x₃ = √0.729 · x₀ + √(1-0.729) · ε
   = 0.854 × 2.0 + √0.271 × ε
   = 1.708 + 0.521·ε
```

若 ε = 1.0，x₃ = 2.229。**信号 1.708 已经和噪声 0.521 同量级**——再走几步就完全被噪声淹没。

### 6.3 逆向（去噪）学习什么

训练时，网络看到 x₃=2.229 和 t=3，要预测 ε=1.0。预测准了，就能算出 x₀ ≈ (x₃ - √0.271×1.0)/√0.729 = (2.229-0.521)/0.854 = 2.0 ✓

> 💡 这就是扩散模型的全部：**前向加已知噪声，网络学预测这个噪声，逆向时用预测的噪声把图"洗"回清晰**。

## 7. MATLAB：1D 扩散演示

```matlab
% ============================================================
% DIFFUSION_DEMO.m
% 1D 扩散模型演示: 前向加噪 → 训练去噪网络 → 逆向生成
% 对应 deep-dives/15-扩散模型.md
% ============================================================
clear; clc;

fprintf('=== 1D 扩散模型演示 ===\n\n');

%% 真实数据分布: 来自两个高斯簇的 1D 点
rng(0);
n_data = 1000;
x0_data = [randn(n_data/2,1)*0.5 - 2; randn(n_data/2,1)*0.5 + 2];  % 双峰

%% 扩散参数
T = 100;
beta = linspace(1e-4, 0.02, T);      % 噪声调度 (线性)
alpha = 1 - beta;                     % α_t
alpha_bar = cumprod(alpha);           % ᾱ_t (累乘)

%% 前向: 取一个真实样本, 逐步加噪
x0 = x0_data(1);
fprintf('真实样本 x0 = %.3f\n', x0);

t_target = 50;
eps_true = randn;
x_t = sqrt(alpha_bar(t_target)) * x0 + sqrt(1 - alpha_bar(t_target)) * eps_true;
fprintf('t=%d 时, x_t = %.3f (真实噪声 ε = %.3f)\n', t_target, x_t, eps_true);

%% 训练一个极简"去噪网络" (线性回归, 预测噪声)
% 构造训练数据: 对每个样本, 随机选 t, 加噪, 记录噪声
n_train = 5000;
X_train = zeros(n_train, 1);   % 输入: (x_t, t) 简化为 x_t
y_train = zeros(n_train, 1);   % 输出: 真实噪声 ε

for i = 1:n_train
    x0 = x0_data(randi(n_data));
    t = randi(T);
    eps = randn;
    x_t_i = sqrt(alpha_bar(t)) * x0 + sqrt(1 - alpha_bar(t)) * eps;
    X_train(i) = x_t_i;
    y_train(i) = eps;
end

% 简化: 学一个线性映射 eps ≈ w * x_t (真实关系非线, 但演示足够)
w = (X_train' * X_train) \ (X_train' * y_train);
fprintf('去噪网络学到的权重 w = %.3f\n\n', w);

%% 逆向采样: 从纯噪声出发, 一步步去噪
x_T = randn;   % 纯噪声
x = x_T;
fprintf('逆向采样 (从噪声 %.3f 出发):\n', x_T);
for t = T:-1:1
    % 预测噪声
    eps_pred = w * x;
    % 去除预测的噪声 (简化 DDPM 采样)
    x = (x - sqrt(1 - alpha_bar(t)) * eps_pred) / sqrt(alpha(t));
end
fprintf('生成的 x0 ≈ %.3f\n', x);
fprintf('(应落在真实数据双峰 [-2, +2] 附近)\n');

%% 可视化: 生成一批样本对比真实分布
n_gen = 5000;
x_gen = zeros(n_gen, 1);
for i = 1:n_gen
    x = randn;
    for t = T:-1:1
        eps_pred = w * x;
        x = (x - sqrt(1 - alpha_bar(t)) * eps_pred) / sqrt(alpha(t));
    end
    x_gen(i) = x;
end

figure('Position', [100 100 800 350]);
subplot(1,2,1); histogram(x0_data, 50); title('真实分布'); xlim([-4 4]);
subplot(1,2,2); histogram(x_gen, 50); title('扩散模型生成'); xlim([-4 4]);
```

> ⚠️ 说明：这个 1D 演示用的是**线性去噪**的简化版，目的是展示"前向加噪→学预测噪声→逆向去噪"的完整闭环。真实 DDPM 用 U-Net 学非线性去噪，但流程结构完全一致。

## 📌 本章要点

1. 扩散 = 前向加噪（固定）+ 逆向去噪（学习），生成 = 从噪声倒走
2. 闭式 `x_t = √ᾱ_t·x₀ + √(1-ᾱ_t)·ε` 让训练一步直达任意 t，高效
3. 训练目标极简：**预测噪声 ε 的 MSE 回归**
4. 采样慢（要 T 步）是主要缺点，DDIM/蒸馏等技术加速
5. Sora/DALL·E/Midjourney 都是它的实现——文生图/文生视频的理论地基
