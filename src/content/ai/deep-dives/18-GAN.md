# GAN——对抗生成的博弈论

> 生成模型四兄弟之一。GAN 用一场"造假者 vs 鉴伪师"的博弈来学生成：生成器造假，判别器打假，两者互相逼对方进步。这一章讲透这个 min-max 博弈的数学，以及它为什么既强大又难训练。

## 1. 核心思想：一场造假与鉴伪的博弈

两个网络对抗训练：

| 网络 | 角色 | 目标 |
|------|------|------|
| 生成器 G(z) | 造假者 | 从噪声 z 生成以假乱真的样本，骗过 D |
| 判别器 D(x) | 鉴伪师 | 分辨输入是真实样本还是 G 造的假 |

```
噪声 z → [生成器 G] → 假样本 G(z) ─┐
                                    ├→ [判别器 D] → 真/假 (0~1)
真实样本 x ─────────────────────────┘
```

训练过程：D 努力把真样本判 1、假样本判 0；G 努力让 D 把它的假样本判 1。**两者互相逼对方变强**，最终 G 生成的分布逼近真实分布。

---

## 2. min-max 目标函数

GAN 的核心是一个极小极大博弈：

```
min_G max_D V(D,G) = E_{x~真实}[log D(x)] + E_{z~噪声}[log(1 - D(G(z)))]
```

- **D 想最大化 V**：第一项让真样本 D(x)→1；第二项让假样本 D(G(z))→0
- **G 想最小化 V**：让第二项尽量小，即让 D(G(z))→1（假样本被当真）

> 💡 理论上，当 G 完全学到真实分布时，最优 D(x) = P真实(x)/(P真实(x)+P生成(x)) = 1/2——判别器无法分辨，博弈达到纳什均衡。

## 3. "判别即信号"：D 怎么教 G

Prince 第 15.1 节强调的关键洞察：**判别器 D 是 G 的"可微损失函数"**。

G 的更新：固定 D，最小化 `E[log(1-D(G(z)))]`。D 告诉 G"你哪里造得不像"，而且这个信号是**可微的**——梯度从 D 反传回 G，告诉它该怎么改 z 的映射才能更像真的。

这就是为什么 GAN 不需要显式定义"图像像不像"的度量——D 自动学到了这个度量，并把它以梯度的形式喂给 G。

## 4. 训练难点：模式崩塌与不稳定

GAN 出了名的难训练，两个核心问题：

| 问题 | 描述 | 缓解 |
|------|------|------|
| **模式崩塌** | G 发现某几个假样本能骗过 D，就只生成这几个（多样性丧失） | minibatch discrimination、Wasserstein GAN |
| **训练不稳定** | G 和 D 的平衡很脆弱，一方太强另一方就学不到 | 交替训练步调、梯度惩罚、谱归一化 |

> 💡 这是 GAN 被扩散模型反超的根本原因：GAN 生成的图像"最锐利"，但训练太脆弱、模式崩塌难根治；扩散模型采样质量追平后，稳定性优势让它成了主流。

## 5. 手算：G 的一步更新

简化：真实分布是单点 x=1.0，噪声 z 也是标量。G(z) = w·z（线性生成器，w 是参数），D(x)=sigmoid(a·x+b)（线性判别器）。

### 5.1 当前状态

设 w=0.5，z=1.0 → 假样本 G(z)=0.5。设 D(x)=sigmoid(2x-2)：

```
D(真实 1.0) = sigmoid(0) = 0.5
D(假 0.5)   = sigmoid(-1) = 0.269
```

D 目前不能很好分辨（真 0.5 vs 假 0.269，接近）。

### 5.2 G 的损失与梯度

G 的损失：`L_G = log(1 - D(G(z))) = log(1 - 0.269) = log(0.731) = -0.313`

G 想最小化 L_G，即最大化 D(G(z))。梯度经 D 反传到 w，方向是"增大 G(z) 让 D 判得更像真"——即让假样本 0.5 → 向 1.0 靠拢。

### 5.3 一轮对抗后

D 更新：把真样本判更高、假样本判更低（拉开差距）。G 更新：把假样本推向真样本方向。反复后 G(z)→1.0，D 无法分辨。

> 这就是 GAN 的精髓：**D 的判别边界和 G 的生成分布，在对抗中互相追赶，最终收敛到真实分布**。

## 6. MATLAB：1D GAN

```matlab
% ============================================================
% GAN_1D.m
% 1D GAN: 生成器学一个高斯分布 (概念演示)
% 对应 deep-dives/18-GAN.md
% ============================================================
clear; clc;

fprintf('=== 1D GAN 演示 ===\n\n');

%% 真实分布: 均值 4 的高斯
rng(0);
real_dist = @(n) 4 + randn(n,1);

%% 生成器 G(z) = w*z + b, 判别器 D(x) = sigmoid(a*x + c)
% 初始化
w = 0.5; b = 0;      % G 参数
a = 1.0; c = 0;      % D 参数
lr = 0.01;
n_iter = 3000;
batch = 64;

for it = 1:n_iter
    % 采样
    z = randn(batch, 1);          % 噪声
    x_real = real_dist(batch);    % 真样本
    x_fake = w*z + b;             % 假样本

    % --- 判别器 D 更新 (想最大化 log D(x_real) + log(1-D(x_fake))) ---
    d_real = sigmoid(a*x_real + c);
    d_fake = sigmoid(a*x_fake + c);

    % 梯度 (对 a, c)
    grad_a = mean(x_real.*(1-d_real)) - mean(x_fake.*d_fake);
    grad_c = mean(1-d_real) - mean(d_fake);

    a = a + lr * grad_a;
    c = c + lr * grad_c;

    % --- 生成器 G 更新 (想最小化 log(1-D(G(z))), 即让 D(G(z))→1) ---
    d_fake = sigmoid(a*x_fake + c);
    % 对 w, b 的梯度 (经 D 反传)
    grad_w = mean(a * (d_fake - 1) .* z);
    grad_b = mean(a * (d_fake - 1));

    w = w - lr * grad_w;
    b = b - lr * grad_b;
end

%% 结果
fprintf('生成器 G(z) = %.2f·z + %.2f\n', w, b);
fprintf('真实分布均值 = 4.0, 生成器学到的均值(偏置b) ≈ %.2f\n\n', b);
fprintf('(b 应收敛到接近 4, 即生成器学出了真实分布的位置)\n');

%% 可视化对比
n = 5000;
z = randn(n,1);
x_gen = w*z + b;
x_real = real_dist(n);

figure('Position', [100 100 800 350]);
subplot(1,2,1); histogram(x_real, 50); title('真实分布'); xlim([-2 10]);
subplot(1,2,2); histogram(x_gen, 50); title('GAN 生成'); xlim([-2 10]);
```

> ⚠️ 说明：这是概念演示（线性 G 和 D）。真实 GAN 用深度网络学任意分布，但"判别器给生成器提供可微信号"的核心机制完全一致。

## 📌 本章要点

1. GAN = 生成器 vs 判别器的 min-max 博弈
2. 判别器是生成器的"可微损失函数"，梯度反传即教学信号
3. 最优时 D(x)=1/2，无法分辨，达到纳什均衡
4. 模式崩塌 + 训练不稳定是两大软肋，被扩散模型反超的原因
5. 代表：StyleGAN（图像生成质量巅峰之一）、CycleGAN（图像翻译）
