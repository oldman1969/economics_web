# VAE——变分自编码器与隐变量

> 生成模型四兄弟之一。VAE 回答的问题是：**怎么让"隐变量 z 的空间"变得可采样、可生成**。普通自编码器的 z 空间是乱码，VAE 强制 z 服从高斯分布，从而能用 `从 z 采样 → 解码` 来生成新数据。这一章讲透 ELBO 和重参数化技巧。

## 1. 从自编码器到隐变量模型

普通自编码器（AE）：

```
编码器: z = enc(x)      (x → z)
解码器: x̂ = dec(z)      (z → x)
损失:   ||x - x̂||²
```

问题：z 空间是**确定性的、不规则的**。两个样本的 z 之间的空隙，解码出来是乱码——所以不能"从 z 空间随机采样来生成"。

VAE 的改造：**让编码器输出一个分布（μ, σ），而不是一个点**：

```
编码器: 输出 q(z|x) = N(z; μ(x), σ²(x))     ← z 服从高斯
解码器: x̂ = dec(z)
```

这样 z 空间被"拉"成连续、规则的高斯分布 → 任意采样一个 z 都能解码出合理图像。

---

## 2. 核心目标：最大化边缘似然

生成模型的统一目标是最大化 P(x)。隐变量模型里：

```
P(x) = ∫ P(x|z) · P(z) dz
```

P(z) = N(0, I) 是先验，P(x|z) 是解码器。但**这个积分一般没有闭式解**——z 的维度太高，无法直接积分。

---

## 3. ELBO：可优化的下界

变分推断的思路：引入一个近似后验 q(z|x)（编码器），推导出 log P(x) 的**下界** ELBO（Evidence Lower Bound）：

```
log P(x) ≥ E_{q(z|x)}[ log P(x|z) ] - KL( q(z|x) || P(z) )
            ↑ 重建项                      ↑ 正则项
```

**两项的直觉**：

| 项 | 含义 | 作用 |
|----|------|------|
| 重建项 E[log P(x\|z)] | 从 z 解码能多好地重建 x | 逼 z 保留 x 的信息 |
| KL(q\|P) | q(z\|x) 离先验 N(0,I) 多远 | 逼 z 空间连续规则、可采样 |

最大化 ELBO = 同时做到"重建得好"和"z 空间像高斯"。两者是**张力**：z 太规则会丢信息（重建差），z 太自由会不连续（不能生成）。

> 💡 KL 项前的权重 β 是著名的 β-VAE 调节旋钮：β>1 强化"规则性"（z 更解耦、可控），但重建质量下降。

---

## 4. 重参数化技巧：让采样可微分

ELBO 里要对 z~q(z|x) 采样，但**采样操作不可微分**——梯度传不过去，VAE 无法训练。

**重参数化技巧**（Kingma & Welling, 2014）把随机性移出网络：

```
不写: z ~ N(μ, σ²)
改写: z = μ + σ ⊙ ε,  其中 ε ~ N(0, I)   ← ε 是外部注入的噪声
```

这样 z 对 μ、σ 是**可微的**（μ 和 σ 是编码器输出的确定量，ε 与参数无关）。梯度可以穿过 z 传到编码器。

---

## 5. 手算：ELBO 的两项

一维情形，编码器输出 μ=1.0, σ=0.5，先验 N(0,1)，采样 ε=0.3：

### 5.1 重参数化

```
z = μ + σ·ε = 1.0 + 0.5×0.3 = 1.15
```

### 5.2 重建项（假设解码器输出 x̂=dec(z)=1.05，真实 x=1.0）

```
log P(x|z) = -||x - x̂||² = -(1.0-1.05)² = -0.0025
```

### 5.3 KL 项（两个一维高斯的 KL 有闭式）

```
KL(N(μ,σ²) || N(0,1)) = 0.5·( μ² + σ² - 1 - log σ² )
                       = 0.5·( 1 + 0.25 - 1 - log(0.25) )
                       = 0.5·( 0.25 + 1.386 )
                       = 0.5 × 1.636 = 0.818
```

### 5.4 ELBO

```
ELBO ≈ -0.0025 - 0.818 = -0.8205
```

> 💡 这个例子重建项很小（重建好），但 KL 项大（z 偏离先验）——说明当前 μ=1 的 z 分布"太集中"，模型需要在"重建"和"规则"之间权衡。

## 6. MATLAB：1D VAE 演示

```matlab
% ============================================================
% VAE_1D.m
% 1D VAE: 编码器输出 (μ,σ), 解码器重建, ELBO 训练
% 对应 deep-dives/20-VAE.md
% ============================================================
clear; clc;

fprintf('=== 1D VAE 演示 ===\n\n');

%% 真实数据: 单峰高斯 (均值3, 方差0.5)
rng(0);
n = 10000;
x_real = 3 + 0.7*randn(n,1);

%% VAE 参数 (线性简化版)
% 编码器: μ = a_mu*x + b_mu, log σ² = a_logvar*x + b_logvar
% 解码器: x̂ = c*z + d
a_mu = 0.5; b_mu = 0;
a_logvar = 0; b_logvar = 0;   % log σ² 从 0 开始
c = 1.0; d = 0;

lr = 0.001;
n_iter = 5000;
batch = 256;

for it = 1:n_iter
    % 采样一个 batch
    idx = randi(n, batch, 1);
    x = x_real(idx);

    % --- 编码器 ---
    mu = a_mu*x + b_mu;
    logvar = a_logvar*x + b_logvar;
    sigma = exp(0.5*logvar);

    % --- 重参数化 ---
    eps = randn(batch, 1);
    z = mu + sigma .* eps;

    % --- 解码器 ---
    x_hat = c*z + d;

    % --- ELBO 损失 (取负, 做最小化) ---
    recon = (x - x_hat).^2;                         % 重建项 (MSE)
    kl = 0.5 * (mu.^2 + sigma.^2 - 1 - logvar);     % KL 项
    loss = mean(recon + kl);

    % --- 梯度 (简化: 数值梯度或解析; 这里用解析) ---
    % 对 mu: d(loss)/d(mu) = 2*(x_hat-x)*c /batch + mu
    d_mu = (2*(x_hat - x)*c)/batch + mu/batch;
    % 对 logvar: 用重参数化的链式
    d_logvar = ( (x_hat - x).*c .* eps .* sigma )/batch + 0.5*(sigma.^2 - 1)/batch;
    % 对 x 的梯度回传到 a_mu, b_mu, a_logvar, b_logvar
    d_x_mu = d_mu .* x;  % 用于 a_mu
    % (完整实现较繁琐, 此处示意)

    % 更新编码器参数
    a_mu = a_mu - lr * mean(d_mu .* x);
    b_mu = b_mu - lr * mean(d_mu);

    % 更新解码器参数
    grad_c = mean(2*(x_hat - x) .* z);
    grad_d = mean(2*(x_hat - x));
    c = c - lr * grad_c;
    d = d - lr * grad_d;
end

%% 结果
fprintf('编码器: μ = %.2f·x + %.2f\n', a_mu, b_mu);
fprintf('解码器: x̂ = %.2f·z + %.2f\n\n', c, d);

%% 生成: 从先验 z~N(0,1) 采样, 走解码器
z_gen = randn(10000, 1);
x_gen = c*z_gen + d;

fprintf('真实分布均值=3.0, 生成分布均值 ≈ %.2f\n', mean(x_gen));
fprintf('(生成器把先验 N(0,1) 映射到数据分布附近)\n');

figure('Position', [100 100 800 350]);
subplot(1,2,1); histogram(x_real, 50); title('真实分布'); xlim([0 6]);
subplot(1,2,2); histogram(x_gen, 50); title('VAE 生成'); xlim([0 6]);
```

> ⚠️ 说明：这是线性 VAE 的概念演示，真实 VAE 用深度网络，但 ELBO 两项 + 重参数化的结构完全一致。

## 📌 本章要点

1. VAE = 自编码器 + 让 z 服从高斯（可采样、可生成）
2. 目标最大化边缘似然 P(x)，因积分难解改用下界 ELBO
3. ELBO = 重建项 + KL 项，两者是"保信息 vs 规则化"的张力
4. 重参数化技巧 z = μ + σε 让采样可微分，是 VAE 能训练的关键
5. 应用：图像生成、异常检测、潜空间插值（如"笑脸连续变化"）
