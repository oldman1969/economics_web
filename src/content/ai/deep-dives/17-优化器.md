## 1. 梯度下降：最朴素的一步

沿负梯度方向走一小步：

```
φ_{t+1} = φ_t - η · ∇L(φ_t)
```

η 是学习率。全量梯度下降（GD）每步要看**所有**训练数据，慢但稳。三个致命问题：

1. 学习率难选（太大震荡，太小龟速）
2. 每个参数用同一个学习率（不同参数尺度不同）
3. 易陷入鞍点/局部最优

后面的优化器都是针对这三个问题打补丁。

---

## 2. SGD：用小批量换速度

随机梯度下降每步只看**一个小批量（minibatch）**的梯度估计：

```
g_t = (1/|B|) Σ_{i∈B} ∇L_i(φ_t)     ← 用 batch 近似全量梯度
φ_{t+1} = φ_t - η · g_t
```

**关键性质**：这个梯度估计有噪声（batch 不同，梯度不同）。噪声是坏事也是好事——它帮模型**逃出尖锐的局部极小**，这本身就是一种隐式正则化（见 deep-dives/12）。

---

## 3. 动量：给梯度加惯性

想象一个小球滚下山，不仅受当前重力（梯度），还有之前的**速度**：

```
v_{t+1} = μ · v_t + g_t          ← 速度累积（μ≈0.9 是动量系数）
φ_{t+1} = φ_t - η · v_{t+1}
```

效果：
- 梯度方向一致时，速度累加 → **加速**
- 梯度来回震荡时，正负抵消 → **抑制震荡**
- 能越过小的平坦区/鞍点

## 4. Adam：自适应学习率

Adam（Kingma & Ba, 2014）= 动量 + 每个参数自适应学习率。维护两个统计量：

```
m_t = β₁·m_{t-1} + (1-β₁)·g_t          ← 梯度的一阶矩（均值，类似动量）
v_t = β₂·v_{t-1} + (1-β₂)·g_t²         ← 梯度的二阶矩（方差）

偏差校正（初期 m、v 偏小）:
m̂_t = m_t / (1-β₁^t)
v̂_t = v_t / (1-β₂^t)

更新:
φ_{t+1} = φ_t - η · m̂_t / (√v̂_t + ε)
```

**直觉**：`1/√v̂_t` 是"按参数缩放的学习率"——梯度一直很大的参数（v 大）走小步，梯度一直很小的参数（v 小）走大步。这让不同尺度的参数都能有效更新。

默认超参：η=0.001，β₁=0.9，β₂=0.999，ε=1e-8。

## 5. 手算：四种更新对比

设当前参数 φ=2.0，连续三步梯度 g = [1.0, 1.0, -1.0]（前两步同向，第三步反向），η=0.1：

### 5.1 朴素 SGD

```
φ₁ = 2.0 - 0.1×1.0 = 1.9
φ₂ = 1.9 - 0.1×1.0 = 1.8
φ₃ = 1.8 - 0.1×(-1.0) = 1.9
```

### 5.2 动量（μ=0.9，v₀=0）

```
v₁ = 0.9×0 + 1.0 = 1.0      → φ₁ = 2.0 - 0.1×1.0 = 1.9
v₂ = 0.9×1.0 + 1.0 = 1.9    → φ₂ = 1.9 - 0.1×1.9 = 1.71
v₃ = 0.9×1.9 - 1.0 = 0.71   → φ₃ = 1.71 - 0.1×0.71 = 1.639
```

> 💡 前两步动量累积速度，比 SGD 走得更远（1.71 vs 1.8 的差距）；第三步梯度反向，但速度仍有惯性，没有立刻掉头。

### 5.3 Adam（β₁=0.9，β₂=0.999，ε=1e-8，η=0.1）

```
g₁=1.0: m₁=0.1×1.0=0.1,  v₁=0.001×1.0²=0.001
        m̂₁=0.1/(1-0.9)=1.0, v̂₁=0.001/(1-0.999)=1.0
        φ₁ = 2.0 - 0.1×1.0/√1.0 = 1.9

g₂=1.0: m₂=0.9×0.1+0.1×1.0=0.19, v₂=0.999×0.001+0.001×1.0=0.002
        m̂₂=0.19/(1-0.81)=1.0, v̂₂=0.002/(1-0.998)=1.0
        φ₂ = 1.9 - 0.1×1.0 = 1.8

g₃=-1.0: m₃=0.9×0.19+0.1×(-1.0)=0.071, v₃=0.999×0.002+0.001×1.0=0.003
         m̂₃=0.071/(1-0.729)=0.262, v̂₃=0.003/(1-0.997)=1.0
         φ₃ = 1.8 - 0.1×0.262/1.0 = 1.774
```

> 注意偏差校正的作用：前几步 `1/(1-β₁^t)` 把 m 从接近 0 拉回真实尺度。这防止了训练初期"起步太慢"。

## 6. MATLAB：优化器对决

```matlab
% ============================================================
% OPTIMIZERS.m
% 对比 GD / Momentum / Adam 在二维凹坑上的收敛速度
% 对应 deep-dives/17-优化器.md
% ============================================================
clear; clc;

fprintf('=== 优化器对决 ===\n\n');

%% 目标函数: L(φ) = φ₁²/20 + φ₂²  (长条形凹坑, 条件数差)
L  = @(p) p(1)^2/20 + p(2)^2;
gL = @(p) [p(1)/10; 2*p(2)];

%% 初始化
p0 = [8; 8];      % 起点
lr = 0.1;
n_iter = 50;

%% 1. 朴素 GD
p = p0; traj_gd = p';
for t = 1:n_iter
    p = p - lr * gL(p);
    traj_gd(end+1,:) = p';
end

%% 2. Momentum
p = p0; v = [0;0]; mu = 0.9; traj_mom = p';
for t = 1:n_iter
    v = mu*v + gL(p);
    p = p - lr * v;
    traj_mom(end+1,:) = p';
end

%% 3. Adam
p = p0; m = [0;0]; vv = [0;0];
b1 = 0.9; b2 = 0.999; eps_ = 1e-8; traj_adam = p';
for t = 1:n_iter
    g = gL(p);
    m = b1*m + (1-b1)*g;
    vv = b2*vv + (1-b2)*g.^2;
    m_hat = m / (1-b1^t);
    v_hat = vv / (1-b2^t);
    p = p - lr * m_hat ./ (sqrt(v_hat) + eps_);
    traj_adam(end+1,:) = p';
end

%% 输出最终损失
fprintf('最终损失 (起点 %.2f):\n', L(p0));
fprintf('  GD:        %.6f\n', L(traj_gd(end,:)'));
fprintf('  Momentum:  %.6f\n', L(traj_mom(end,:)'));
fprintf('  Adam:      %.6f\n', L(traj_adam(end,:)'));

%% 可视化
figure('Position', [100 100 700 500]);
% 画损失等高线
[X1, X2] = meshgrid(linspace(-10,10,100));
Z = X1.^2/20 + X2.^2;
contour(X1, X2, Z, 30); hold on;
plot(traj_gd(:,1), traj_gd(:,2), 'b-o', 'MarkerSize', 3, 'LineWidth', 1);
plot(traj_mom(:,1), traj_mom(:,2), 'r-s', 'MarkerSize', 3, 'LineWidth', 1);
plot(traj_adam(:,1), traj_adam(:,2), 'g-^', 'MarkerSize', 3, 'LineWidth', 1);
legend('等高线', 'GD', 'Momentum', 'Adam', 'Location', 'northwest');
title('长条形凹坑: 动量与 Adam 显著减少震荡'); grid on;
```

运行后：GD 在长条形凹坑里来回震荡收敛慢，动量减少震荡，Adam 最快到达中心——直观展示三个优化器的递进。

## 📌 本章要点

1. 梯度下降的三个问题：学习率、逐参数尺度、鞍点
2. SGD 的噪声既是代价也是隐式正则化
3. 动量累积速度 → 加速 + 抑震
4. Adam = 动量 + 自适应学习率（一阶矩 + 二阶矩），工业默认
5. 偏差校正是 Adam 初期不"起步慢"的关键
