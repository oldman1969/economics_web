## 1. 核心思想：把复杂分布"扭"成高斯

归一化流的目标是学一个**可逆映射** f，把复杂数据分布 P(x) 变换成简单的高斯分布 P(z)=N(0,I)：

```
数据 x ~ P(x)  --f-->  z ~ N(0, I)
          ←-- f⁻¹--

生成时: 从高斯采样 z, 走 f⁻¹(z) 得到新数据 x
```

因为 f 可逆，x 和 z 一一对应，概率密度可以**精确**换算（不像 GAN/VAE 只能近似）。

---

## 2. 变量替换公式：密度的守恒定律

这是归一化流的灵魂——概率密度在变量替换下的变化规律：

```
p_x(x) = p_z(f(x)) · |det J_f(x)|
```

其中 J_f(x) = ∂f/∂x 是 f 的**雅可比矩阵**，|det| 是它的行列式绝对值。

### 直觉

如果 f 把一小块 x 空间"拉伸"了（体积变大），那么这一块的概率密度就**稀释**了（除以拉伸倍数）。|det J_f| 就是"局部体积变化率"。

### 1D 特例

一维时雅可比退化为标量导数 f'：

```
p_x(x) = p_z(f(x)) · |f'(x)|
```

### 对数形式（实际计算用）

```
log p_x(x) = log p_z(f(x)) + log |det J_f(x)|
```

多步串联（f = f_K ∘ ... ∘ f₁）时，行列式可乘（对数可加）：

```
log p_x(x) = log p_z(f(x)) + Σ_k log |det J_{f_k}|
```

> 💡 训练目标就是最大化这个 log 似然——**精确、无下界、无对抗**，是四种生成模型里训练最稳定的。

## 3. 可逆层的设计

关键工程难题：怎么设计**可逆 + 行列式好算**的神经网络层？

| 层 | 可逆性 | 行列式 |
|----|--------|--------|
| 仿射层 z = ax + b（a≠0） | 直接逆 | a（标量） |
| 耦合层（RealNVP） | 用掩码保证部分可逆 | 三角矩阵，行列式=对角线乘积 |
| 反转层（GLOW） | 1×1 可逆卷积 | 小矩阵行列式 |

**耦合层（最常用）**：把 x 劈成两半 x=(x_a, x_b)，前向时 x_a 原样通过，x_b 经一个（任意复杂、无需可逆的）网络变换：

```
z_a = x_a
z_b = x_b ⊙ exp(s(x_a)) + t(x_a)     ← s、t 是普通网络
```

逆变换直接可算（因为 x_a 已知），雅可比是三角矩阵，行列式 = Π exp(s(x_a))——好算。

## 4. 手算：1D 归一化流

### 4.1 设定

真实数据分布是"双峰"（两个高斯簇）。学一个可逆映射 f 把它变回标准正态。

简化：设 f(x) = x + a·tanh(x)（可逆的"挤压"变换），a 是参数。

### 4.2 密度换算

```
f'(x) = 1 + a·(1 - tanh²(x))

log p_x(x) = log p_z(f(x)) + log |1 + a(1-tanh²(x))|
           = -f(x)²/2 - 0.5·log(2π) + log |1 + a(1-tanh²(x))|
```

### 4.3 具体数值

设 a=1.0，x=1.0：

```
f(1.0) = 1.0 + tanh(1.0) = 1.0 + 0.762 = 1.762
f'(1.0) = 1 + (1 - 0.762²) = 1 + (1-0.581) = 1.419

log p_x(1.0) = -1.762²/2 - 0.5·log(2π) + log(1.419)
             = -1.552 - 0.919 + 0.350
             = -2.121
```

x=1.0 处的密度 ≈ e^{-2.121} ≈ 0.120。

> 💡 通过 f 和它的导数，我们就**精确地**算出了任意 x 处的概率密度——不需要采样近似，不需要对抗训练。这就是归一化流的优雅。

---

## 5. 为什么要求"可逆 + 行列式好算"

| 要求 | 原因 |
|------|------|
| 可逆 | 生成时要走 f⁻¹（从 z 到 x） |
| 行列式好算 | 训练时每步都要算 log det J（否则计算量爆炸） |

这两个要求同时满足很难：**可逆的网络架构受限**（不能随便堆层），这限制了归一化流的表达力——它需要比 VAE/GAN 多得多的参数才能表达同等复杂度的分布。

## 6. MATLAB：1D 流演示

```matlab
% ============================================================
% NORMALIZING_FLOW_1D.m
% 1D 归一化流: 用可逆变换拟合双峰分布, 精确计算密度
% 对应 deep-dives/19-归一化流.md
% ============================================================
clear; clc;

fprintf('=== 1D 归一化流 ===\n\n');

%% 真实数据: 双峰分布
rng(0);
n = 20000;
x_real = [randn(n/2,1) - 2; randn(n/2,1) + 2];

%% 定义可逆变换族: f(x) = x + a*tanh(x)
% 训练 a, 使 f(x_real) 尽量接近标准正态
a = 0;   % 初始参数
lr = 0.01;
n_iter = 2000;

for it = 1:n_iter
    % 前向: z = f(x)
    z = x_real + a * tanh(x_real);

    % 导数: f'(x) = 1 + a*(1 - tanh²(x))
    dfdx = 1 + a * (1 - tanh(x_real).^2);

    % log 似然: log p_x = log p_z(f(x)) + log |f'(x)|
    log_p = -z.^2/2 - 0.5*log(2*pi) + log(abs(dfdx));

    % 损失 = 负 log 似然
    loss = -mean(log_p);

    % 梯度 (对 a)
    grad = mean( tanh(x_real).*z + (1 - tanh(x_real).^2)./dfdx );

    a = a + lr * grad;   % 梯度上升最大化似然
end

fprintf('学到的参数 a = %.3f\n', a);
fprintf('(a>0 表示把双峰"向外拉伸"成单峰高斯)\n\n');

%% 用学到的 f 生成新样本: 从高斯采样 z, 走 f^{-1}
% f(x) = x + a*tanh(x) 的逆: 数值求解
n_gen = 10000;
z_gen = randn(n_gen, 1);
x_gen = zeros(n_gen, 1);
for i = 1:n_gen
    % 牛顿法求 x 使 f(x)=z
    x = z_gen(i);
    for k = 1:20
        fx = x + a*tanh(x);
        dfx = 1 + a*(1-tanh(x)^2);
        x = x - (fx - z_gen(i)) / dfx;
    end
    x_gen(i) = x;
end

%% 对比
fprintf('真实分布: 双峰 (-2 和 +2)\n');
fprintf('生成分布: 从高斯经 f^{-1} 采样\n\n');

figure('Position', [100 100 800 350]);
subplot(1,2,1); histogram(x_real, 50); title('真实 (双峰)'); xlim([-6 6]);
subplot(1,2,2); histogram(x_gen, 50); title('归一化流生成'); xlim([-6 6]);
```

## 📌 本章要点

1. 归一化流 = 可逆映射把数据分布扭成高斯，生成时逆走
2. 变量替换公式 `p_x = p_z(f(x))·|det J|` 是灵魂，能**精确**算似然
3. 多步串联时行列式对数可加，训练极稳定
4. 代价：可逆架构受限，表达力需更多参数
5. 代表：RealNVP、GLOW；应用：密度估计、图像生成、语音合成
